# solutions

本文（`docs/NN.md`）からリンクする **解答例・サンプルコード** を置くディレクトリです。

## ディレクトリ規則

```
solutions/
  python/{章番号}/{問題ID}/main.py
  go/{章番号}/{問題ID}/main.go
```

| プレースホルダ | 意味 | 例 |
|----------------|------|-----|
| `{章番号}` | `docs/NN.md` の **NN**（Part 番号と一致） | `01` = [docs/01.md](../docs/01.md)（灰色） |
| `{問題ID}` | AtCoder 問題のスラッグ | `abc200_a` |

- 1 問題 1 ディレクトリを基本とする。
- ファイル名は言語ごとに `main.py` / `main.go`（複数解法がある場合は `main_fast.go` などサフィックス可）。

## 本文との対応

| docs | Part | solutions 例 |
|------|------|----------------|
| 00.md | はじめに | `python/00/`, `go/00/`（テンプレ・A+B） |
| 01.md | 灰色 | `python/01/...`, `go/01/...` |
| 02.md | 茶色 | `python/02/...`, `go/02/...` |

## テスト（任意）

- Python: `pytest` でサンプル入出力を検証（`pyproject.toml` の `[dev]` 参照）。
- Go: `go test` を同ディレクトリに置くか、`go run` で手動確認。

AtCoder から取得したローカルテストデータは **リポジトリに含めない**。
