## 解き方のメモ（本文で解説していない問題）

本文の表にだけ載せている問題の方針です。まず自分で考えてから読んでください。

- **[agc024_d](https://atcoder.jp/contests/agc024/tasks/agc024_d)**（[agc024_d/](agc024_d/)）: 色の数の最小は「直径の半分 + 1」。中心（頂点 1 つか辺 1 本）を全部試し、同じ深さの頂点の子の数をその深さの最大にそろえると、葉の数はその積になる。
- **[agc026_d](https://atcoder.jp/contests/agc026/tasks/agc026_d)**（[agc026_d/](agc026_d/)）: ヒストグラムを、一番低い高さで切った長方形とその上の区間に分けて再帰する。ある行が赤青交互なら上下の行も交互、交互でなければ上下はその反転に決まる、という性質で「最下行が交互の塗り方」と「全体」の 2 つを数える。
- **[agc028_d](https://atcoder.jp/contests/agc028/tasks/agc028_d)**（[agc028_d/](agc028_d/)）: 連結成分を「その成分の一番左の点 l と一番右の点 r」で数える（主客転倒）。dp[l][r] を「区間 [l, r] の中だけで組み、l と r が同じ成分になる方法の数」とし、区間 DP で求める。
- **[agc029_e](https://atcoder.jp/contests/agc029/tasks/agc029_e)**（[agc029_e/](agc029_e/)）: 1 を根にし、各頂点の答えを親の答えとの差で求める。差は「親から根までの道の最大 ID」との大小で場合分けでき、部分木の中で x 未満の ID だけを通って行ける頂点の数をメモ化して数える。
- **[agc030_f](https://atcoder.jp/contests/agc030/tasks/agc030_f)**（[agc030_f/](agc030_f/)）: 組を「両方決まっている」「片方だけ決まっている」「両方 -1」に分ける。値を大きい方から見て、相手の決まっていない値の数を状態に持つ DP をし、両方 -1 の組の区別は最後に c! を掛けてつける。
- **[arc170_e](https://atcoder.jp/contests/arc170/tasks/arc170_e)**（[arc170_e/](arc170_e/)）: 処理は長さ N − 1 の L / R の列（同じ文字が続く確率 p）に対応し、距離の和は「同じ文字の組 (i ≤ j) の数」に書き直せる。期待値の線形性で、等比数列の和として閉じた式にする。
- **[arc171_e](https://atcoder.jp/contests/arc171/tasks/arc171_e)**（[arc171_e/](arc171_e/)）: 勝てる配置では、黒石は縦と横に交互に動き、白石は隣り合う 2 行（2 列）の組に並ぶ。組を訪れる順番で配置が決まるので、行方向と列方向を別々に数えて掛ける（M が奇数なら 0）。
