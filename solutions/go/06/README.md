## 解き方のメモ（本文で解説していない問題）

本文の表にだけ載せている問題の方針です。まず自分で考えてから読んでください。

- **[agc022_a](https://atcoder.jp/contests/agc022/tasks/agc022_a)**（[agc022_a/](agc022_a/)）: 使っていない文字があれば、一番小さいものを末尾に足す。26 文字全部使っているときは、後ろから見て「それより後ろにある大きい文字に替えられる」一番後ろの位置 i を探し、s[:i] に s[i] より大きい最小の文字を付ける。
- **[arc141_c](https://atcoder.jp/contests/arc141/tasks/arc141_c)**（[arc141_c/](arc141_c/)）: 辞書順最小の順列 P で、隣り合う 2 つが「大きい添字 → 小さい添字」の順なら、それは「(」→「)」と決まる（最大の Q では逆）。こうして括弧列を決め、そこから最小・最大の順列を作り直して入力と一致するか確かめる。
- **[arc142_d](https://atcoder.jp/contests/arc142/tasks/arc142_d)**（[arc142_d/](arc142_d/)）: 条件を満たす置き方は、頂点全体を 2 頂点以上のパスに分け、各パスの片方の端だけ駒を置かない形になる。パスのつながり方（端点どうし・内部どうし）を状態に持つ木 DP で数える。
- **[arc144_c](https://atcoder.jp/contests/arc144/tasks/arc144_c)**（[arc144_c/](arc144_c/)）: 各位置には差が K 以上の値しか置けない（N < 2K なら -1）。残りが 4K を超える間は、先頭 2K 個を (K + 1, …, 2K, 1, …, K) で埋めるのが辞書順最小。最後の 2K〜4K 個は別に決める。
- **[arc146_d](https://atcoder.jp/contests/arc146/tasks/arc146_d)**（[arc146_d/](arc146_d/)）: 条件を「A_P ≥ X ならば A_Q ≥ Y」の形の含意 4 本に言い換える。全部 1 から始め、破られている含意があれば値を上げる、をくり返す（値は下がらないので、上限を超えたら -1）。
