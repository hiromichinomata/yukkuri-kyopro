## 解き方のメモ（本文で解説していない問題）

本文の表にだけ載せている問題の方針です。まず自分で考えてから読んでください。

- **[agc018_c](https://atcoder.jp/contests/agc018/tasks/agc018_c)**（[agc018_c/](agc018_c/)）: 「銀にする得 − 銅にする得」の大きい順に並べると、銀の人は銅の人より前に来る。境界を全部試し、前の人から銀を Y 人、後ろの人から銅を Z 人、ヒープで得の大きい人を選ぶ。
- **[agc021_c](https://atcoder.jp/contests/agc021/tasks/agc021_c)**（[agc021_c/](agc021_c/)）: 盤面を 2×2 のブロックに分けて 1×2・2×1 を入れ、N や M が奇数なら最後の行・列に寄せて置く。両方奇数のときは、右下 3×3 に風車型の配置を使う場合も試す。
- **[arc163_d](https://atcoder.jp/contests/arc163/tasks/arc163_d)**（[arc163_d/](arc163_d/)）: トーナメントの強連結成分は一列に並ぶので、成分の数は「すべての辺が A から B へ向く分割 (A, B)（A は空でない）」の数と同じ。頂点を番号順に A か B に振り分ける DP で、分割とトーナメントの組を数える。
- **[arc165_e](https://atcoder.jp/contests/arc165/tasks/arc165_e)**（[arc165_e/](arc165_e/)）: 操作は「頂点の一様ランダムな順列の順に、K + 1 頂点以上の成分にいる頂点だけを選ぶ」と同じ。期待値の線形性で、連結な集合ごとの確率を、大きさと境界の数ごとに木 DP で数えて足す。
- **[arc166_e](https://atcoder.jp/contests/arc166/tasks/arc166_e)**（[arc166_e/](arc166_e/)）: 最長の区間では、両端のすぐ外が a の倍数になる。長さを式で求めたあと、b の倍数との位置の条件を「a x mod b が範囲に入る最小の x」に言い換え、互除法と同じ形の再帰で O(log) で求める。
- **[arc167_e](https://atcoder.jp/contests/arc167/tasks/arc167_e)**（[arc167_e/](arc167_e/)）: S = 1, 2, 3, 5, 7 は作れない（座標の範囲を絞った全探索で確かめられる）。S = 4 は手で作る。それ以外は p + q + 1 = S となる互いに素な p, q ≥ 2 を選び、拡張ユークリッドの互除法で面積 S/2 の三角形を作る。
