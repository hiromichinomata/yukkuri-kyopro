## 8.1 問題の分解と考察

**霊夢**: 赤色って、テンプレが分かっても解けないことが多いのよね……

**魔理沙**: 赤色は **「何を聞いているか」** の翻訳が半分だ。次のチェックリストを紙に書け。

| 段階 | 質問 |
|------|------|
| 制約 | N, Q, 値域、mod、木か一般グラフか |
| 弱い制約 | 小さい N で全探索・MITM が効くか |
| 強い制約 | 線形・対数・√ しか通らないか → データ構造の候補 |
| 言い換え | 「操作の列」→「不変量」「潜在値」「グラフ上の状態」 |
| 部分点 | 小さいケースだけ先に AC してヒントにする |

→ [solutions/python/08/constraint_sheet/](../solutions/python/08/constraint_sheet/) / [solutions/go/08/constraint_sheet/](../solutions/go/08/constraint_sheet/)

```python
def analyze_constraints(n, q, vmax, graph=False):
    """執筆用メモ: 紙の代わりにログへ"""
    hints = []
    if n <= 20:
        hints.append("bitmask / meet-in-the-middle")
    if n <= 2000 and q <= 2000:
        hints.append("O(N^2) DP or Floyd")
    if graph:
        hints.append("tree? -> LCA/HLD; general -> flow/SCC/2-SAT")
    if q >= 10**5:
        hints.append("log or sqrt decomposition, segtree/Fenwick")
    return hints
```

## 8.2 先進的データ構造

**霊夢**: セグ木の応用、まだ足りない？

**魔理沙**: 赤色で出やすいのは **Segment Tree Beats**（区間 chmin + 和）、**モノイドセグ木**、**Wavelet Tree**（k 番目・ランク）だ。

### Segment Tree Beats（区間 chmin）

最大値に対する chmin を遅延伝播で落とし、和を維持する。

→ [solutions/python/08/segbeats/](../solutions/python/08/segbeats/) / [solutions/go/08/segbeats/](../solutions/go/08/segbeats/)

```python
class SegBeats:
    def __init__(self, arr):
        n = len(arr)
        self.n = n
        size = 4 * n
        self.sum = [0] * size
        self.mx = [0] * size
        self.se = [0] * size
        self.cnt = [0] * size
        self._build(arr, 1, 0, n - 1)

    def _push_up(self, i):
        self.sum[i] = self.sum[i * 2] + self.sum[i * 2 + 1]
        mx1, mx2 = self.mx[i * 2], self.mx[i * 2 + 1]
        if mx1 >= mx2:
            self.mx[i], self.se[i], self.cnt[i] = mx1, self.se[i * 2], self.cnt[i * 2]
        else:
            self.mx[i], self.se[i], self.cnt[i] = mx2, self.se[i * 2 + 1], self.cnt[i * 2 + 1]
        if self.se[i] < mx1:
            self.se[i] = max(self.se[i], mx1 if mx1 < mx2 else mx2)
```

### モノイドセグ木

演算と単位元を渡す汎用セグ木。区間「最大」「和」「gcd」などを統一インターフェースで。

→ [solutions/python/08/monoid_seg/](../solutions/python/08/monoid_seg/) / [solutions/go/08/monoid_seg/](../solutions/go/08/monoid_seg/)

```python
class MonoidSeg:
    def __init__(self, data, op, e):
        self.n = len(data)
        self.op = op
        self.e = e
        size = 1
        while size < self.n:
            size <<= 1
        self.size = size
        self.dat = [e] * (2 * size)
        for i, x in enumerate(data):
            self.dat[size + i] = x
        for i in range(size - 1, 0, -1):
            self.dat[i] = op(self.dat[i * 2], self.dat[i * 2 + 1])
```

### Wavelet Tree（入門）

静的配列の **ランク・k 番目** を O(log σ) で。座標圧縮した値域で二分する。

→ [solutions/python/08/wavelet/](../solutions/python/08/wavelet/) / [solutions/go/08/wavelet/](../solutions/go/08/wavelet/)

```python
class Wavelet:
    def __init__(self, arr):
        self.arr = arr
        self.n = len(arr)
        vals = sorted(set(arr))
        self.comp = {v: i for i, v in enumerate(vals)}
        self.levels = []
        lo, hi = 0, len(vals) - 1
        while lo < hi:
            mid = (lo + hi) // 2
            bit = [0]
            for x in arr:
                c = self.comp[x]
                bit.append(bit[-1] + (1 if c > mid else 0))
            self.levels.append((lo, hi, mid, bit))
            # 次のレベルへ分割（実装は solutions 参照）
            break
```

## 8.4 計算量の下限と最適化

**霊夢**: もう計算量のオーダーは分かるのに、TLE する……

**魔理沙**: 赤色 TLE の多くは **定数・枝刈り・メモリ局所性** だ。

| 技法 | 内容 |
|------|------|
| 枝刈り | 上界・下界で探索を切る（例: 部分和） |
| 定数削減 | `sys.stdin.buffer`、再帰→反復、配列の再利用 |
| メモリ | `__slots__`、不要なコピー削減 |
| 並列化 | PyPy / Go / C++ への切り替え |

→ [solutions/python/08/branch_bound/](../solutions/python/08/branch_bound/) / [solutions/go/08/branch_bound/](../solutions/go/08/branch_bound/)

```python
def subset_sum_pruned(xs, target):
    xs = sorted(xs, reverse=True)
    best = [False]

    def dfs(i, rem):
        if rem == 0:
            best[0] = True
            return
        if rem < 0 or i == len(xs):
            return
        if sum(xs[i:]) < rem:
            return
        dfs(i + 1, rem - xs[i])
        if best[0]:
            return
        dfs(i + 1, rem)

    dfs(0, target)
    return best[0]
```

**霊夢**: 「理論上は通るのに通らない」は心が折れる……

**魔理沙**: まず **部分点の小さい制約** で正しさを固め、定数は後から。AGC F はここが勝負になることもある。

## 8.5 赤色演習：読解と再現

**霊夢**: 長編って、一問ずつじっくり？

**魔理沙**: 赤色の学び方は **読む → 真似る → 伸ばす** の 3 段。ここでは **読解の型** を 1 問分、対談で追う（全文 AC コードは載せない）。

### 例: 難問を「翻訳」する（arc170_e 風の読み方）

**霊夢**: 問題文が長い……

**魔理沙**: 次の順でメモを取れ。

1. **入力・出力** を 1 行ずつ日本語化  
2. **サンプル 1** を手で trace（5 分）  
3. **あり得る解法タグ** を 3 個まで書く（例: 「フロー」「DP」「データ構造」）  
4. **否定**: なぜ greedy だけではダメか、反例を 1 つ  
5. **公式解説を読んだあと**: 自分のメモと diff を 3 行  

→ [solutions/python/08/study_log/](../solutions/python/08/study_log/)（再現用テンプレ）

```python
STUDY_TEMPLATE = """
# 問題 ID:
# 日付:

## サンプル trace
## 解法候補 (最大3)
## 実装メモ (テンプレ名)
## 公式解説後の diff
"""
```

**魔理沙**: 再現週間では **同じ技法の別問題** を 1 問だけ解く。完コピより **テンプレの転用** を狙え。
