## 入出力

### テンプレート

```go
package main

import (
	"bufio"
	"fmt"
	"os"
)

func main() {
	in := bufio.NewReader(os.Stdin)
	out := bufio.NewWriter(os.Stdout)
	defer out.Flush()

	var n int
	fmt.Fscan(in, &n)
	ans := n // ここに解法を書く
	fmt.Fprintln(out, ans)
}
```

### 1 行・複数整数

```go
var a, b int
fmt.Fscan(in, &a, &b)

var n int
fmt.Fscan(in, &n)
a := make([]int, n)
for i := 0; i < n; i++ {
	fmt.Fscan(in, &a[i])
}
```

### 文字列 1 行

```go
var s string
fmt.Fscan(in, &s)
// 空白なし 1 文字列は Fscan で 1 トークン
```

### Scanner（空白区切りで 1 語ずつ）

```go
sc := bufio.NewScanner(os.Stdin)
sc.Buffer(make([]byte, 1024*1024), 1<<20) // 既定では 64KB を超える語・行を読めない
sc.Split(bufio.ScanWords)                 // 外すと 1 行ずつ読む
sc.Scan()
s := sc.Text()
```

## `container/heap`

最小ヒープ（`Less` で小さい方が先）:

```go
import "container/heap"

type Item struct {
	v, idx int
}
type PQ []Item

func (p PQ) Len() int           { return len(p) }
func (p PQ) Less(i, j int) bool { return p[i].v < p[j].v }
func (p PQ) Swap(i, j int)      { p[i], p[j] = p[j], p[i] }
func (p *PQ) Push(x any)        { *p = append(*p, x.(Item)) }
func (p *PQ) Pop() any {
	old := *p
	n := len(old)
	x := old[n-1]
	*p = old[:n-1]
	return x
}

pq := &PQ{}
heap.Init(pq)
heap.Push(pq, Item{v: 0})
```

最大ヒープは `Less` を逆にするか、値を負にする。

## 数値・mod

```go
const mod = 1_000_000_007

func powMod(a, e int) int {
	res := 1
	a %= mod
	for e > 0 {
		if e&1 == 1 {
			res = res * a % mod
		}
		a = a * a % mod
		e >>= 1
	}
	return res
}
```

`math/big` は重いので、通常は 64bit + mod で足りる。

## 再帰

Go のスタックは自動で伸びる（上限は 64 ビット環境で 1GB）ので、深さ 10^6 程度の DFS ならそのまま再帰で書ける。Python のような上限の設定は要らない。

```go
var dfs func(v int)
dfs = func(v int) { // クロージャで再帰するときは、先に var で宣言する
	seen[v] = true
	for _, to := range g[v] {
		if !seen[to] {
			dfs(to)
		}
	}
}
dfs(0)
```

それより深い場合や、再帰の順序を細かく制御したい場合は、明示的なスタックで書く。

```go
stack := []int{start}
for len(stack) > 0 {
	v := stack[len(stack)-1]
	stack = stack[:len(stack)-1]
	// ...
}
```
