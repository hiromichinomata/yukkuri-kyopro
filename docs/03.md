## 3.1 深さ優先探索・幅優先探索

**霊夢**: [02.md](02.md) でグリッドは読めるようになった。でも最短歩数って、どう求めるの？

**魔理沙**: **BFS（幅優先探索）** だ。重みのない迷路では、はじめて到達したときの距離が最短になる。

| 手法 | 向いていること | データ構造 |
|------|----------------|------------|
| BFS | 最短歩数・層の拡張 | キュー |
| DFS | 連結成分・全探索・バックトラック | スタック / 再帰 |

#### グリッド BFS（Python）

→ [solutions/python/03/grid_bfs/](../solutions/python/03/grid_bfs/) / [solutions/go/03/grid_bfs/](../solutions/go/03/grid_bfs/)

```python
from collections import deque
import sys

def bfs(grid, si, sj):
    h, w = len(grid), len(grid[0])
    dist = [[-1] * w for _ in range(h)]
    dist[si][sj] = 0
    q = deque([(si, sj)])
    di = (-1, 1, 0, 0)
    dj = (0, 0, -1, 1)
    while q:
        i, j = q.popleft()
        for k in range(4):
            ni, nj = i + di[k], j + dj[k]
            if 0 <= ni < h and 0 <= nj < w and grid[ni][nj] != "#" and dist[ni][nj] == -1:
                dist[ni][nj] = dist[i][j] + 1
                q.append((ni, nj))
    return dist
```

```go
dist := make([][]int, h)
for i := range dist {
    dist[i] = make([]int, w)
    for j := range dist[i] {
        dist[i][j] = -1
    }
}
type pos struct{ i, j int }
q := []pos{{si, sj}}
dist[si][sj] = 0
for head := 0; head < len(q); head++ {
    p := q[head]
    // 4 近傍を見て dist[ni][nj] == -1 なら更新して q に追加
}
```

#### DFS で連結成分のサイズ

→ [solutions/python/03/grid_dfs/](../solutions/python/03/grid_dfs/) / [solutions/go/03/grid_dfs/](../solutions/go/03/grid_dfs/)

```python
import sys

sys.setrecursionlimit(10**7)

def dfs(i, j, grid, seen):
    h, w = len(grid), len(grid[0])
    seen[i][j] = True
    size = 1
    for di, dj in [(-1, 0), (1, 0), (0, -1), (0, 1)]:
        ni, nj = i + di, j + dj
        if 0 <= ni < h and 0 <= nj < w and not seen[ni][nj] and grid[ni][nj] == ".":
            size += dfs(ni, nj, grid, seen)
    return size
```

**魔理沙**: [00.md](00.md) のとおり `setrecursionlimit` を上げる。それでもダメなら **スタックで明示 DFS** に切り替える（水色以降で詳しくする）。

## 3.2 二分探索

**霊夢**: ソート済みの配列から、○以上の最小値を探す……？

**魔理沙**: **二分探索** だ。緑では次の 2 種類が重要だ。

1. **配列の中**（`lower_bound` 相当）  
2. **答えの二分**（`check(x)` が単調になるとき）  

#### lower_bound 相当（Python）

→ [solutions/python/03/lower_bound/](../solutions/python/03/lower_bound/) / [solutions/go/03/lower_bound/](../solutions/go/03/lower_bound/)

```python
import bisect

a = [1, 3, 3, 5, 7]
# x 以上の最小の位置（0-indexed）
i = bisect.bisect_left(a, 4)
print(i)  # 3（値 5 の位置）
```

```python
def lower_bound(a, x):
    ng, ok = -1, len(a)
    while ok - ng > 1:
        mid = (ok + ng) // 2
        if a[mid] >= x:
            ok = mid
        else:
            ng = mid
    return ok
```

```python
def check(x: int) -> bool:

def max_ok(lo: int, hi: int) -> int:
```

## 3.3 スタック・キュー・deque

**霊夢**: BFS はキューって言ってたよね。他に何に使うの？

**魔理沙**: **スタック** は括弧の対応、**deque** はスライディングウィンドウの定番だ。

#### 括弧の対応（スタック）

→ [solutions/python/03/stack_brackets/](../solutions/python/03/stack_brackets/) / [solutions/go/03/stack_brackets/](../solutions/go/03/stack_brackets/)

```python
def valid_parentheses(s: str) -> bool:
    st = []
    pair = {")": "(", "]": "[", "}": "{"}
    for ch in s:
        if ch in "([{":
            st.append(ch)
        elif ch in ")]}":
            if not st or st[-1] != pair[ch]:
                return False
            st.pop()
        else:
            return False
    return len(st) == 0
```

```go
for i := 0; i < len(s); i++ {

```

#### スライディングウィンドウ（deque）

→ [solutions/python/03/deque_window/](../solutions/python/03/deque_window/) / [solutions/go/03/deque_window/](../solutions/go/03/deque_window/)

長さ `k` の連続部分の最大和の例（累積和でも可）。

```python
from collections import deque

def max_sum_k(xs, k):
    q = deque()
    s = 0
    ans = -10**18
    for i, x in enumerate(xs):
        s += x
        q.append(i)
        if len(q) > k:
            s -= xs[q.popleft()]
        if i >= k - 1:
            ans = max(ans, s)
    return ans
```

## 3.4 動的計画法（入門）

**霊夢**: DP って、何をメモするの？

**魔理沙**: **部分問題の答えを表に保存** して、同じ計算を繰り返さない技法だ。緑では次の 3 つを押さえる。

| 名前 | 状態の例 | 遷移 |
|------|----------|------|
| ナップサック | `dp[i][w]` = 先頭 i 個までで重さ w | 取る / 取らない |
| LIS | `dp[i]` = 末尾 i の LIS 長 | 前の j < i を見る |
| 経路数 | `dp[i][j]` = マスの到達方法数 | 上・左から |

#### 01 ナップサック（Python）

→ [solutions/python/03/knapsack/](../solutions/python/03/knapsack/) / [solutions/go/03/knapsack/](../solutions/go/03/knapsack/)

```python
def knapsack(weights, values, cap):
    n = len(weights)
    dp = [0] * (cap + 1)
    for i in range(n):
        w, v = weights[i], values[i]
        for c in range(cap, w - 1, -1):  # 逆順が重要
            dp[c] = max(dp[c], dp[c - w] + v)
    return dp[cap]
```

```go
dp := make([]int, cap+1)
for i := 0; i < n; i++ {
    w, v := weights[i], values[i]
    for c := cap; c >= w; c-- {
        if dp[c-w]+v > dp[c] {
            dp[c] = dp[c-w] + v
        }
    }
}
```

#### LIS（O(N^2)）

→ [solutions/python/03/lis/](../solutions/python/03/lis/) / [solutions/go/03/lis/](../solutions/go/03/lis/)

```python
def lis(a):
    n = len(a)
    dp = [1] * n
    for i in range(n):
        for j in range(i):
            if a[j] < a[i]:
                dp[i] = max(dp[i], dp[j] + 1)
    return max(dp)
```

#### 経路数（右・下のみ）

→ [solutions/python/03/dp_paths/](../solutions/python/03/dp_paths/) / [solutions/go/03/dp_paths/](../solutions/go/03/dp_paths/)

```python
def paths(h, w, blocked):
    dp = [[0] * w for _ in range(h)]
    dp[0][0] = 0 if blocked[0][0] else 1
    for i in range(h):
        for j in range(w):
            if blocked[i][j]:
                dp[i][j] = 0
                continue
            if i:
                dp[i][j] += dp[i - 1][j]
            if j:
                dp[i][j] += dp[i][j - 1]
    return dp[h - 1][w - 1]
```

## 3.5 グラフの基礎

**霊夢**: グラフって、線でつながった点？

#### 隣接リスト（Python）

→ [solutions/python/03/graph_adj_list/](../solutions/python/03/graph_adj_list/) / [solutions/go/03/graph_adj_list/](../solutions/go/03/graph_adj_list/)

```python
n, m = 5, 4
g = [[] for _ in range(n)]

for u, v in edges:
    g[u].append(v)

```

```go
g := make([][]int, n)

    u, v := e[0], e[1]

```

#### 木の DFS（親・深さ）

→ [solutions/python/03/tree_dfs/](../solutions/python/03/tree_dfs/) / [solutions/go/03/tree_dfs/](../solutions/go/03/tree_dfs/)

```python
import sys

sys.setrecursionlimit(10**7)

def dfs(v, parent, g, depth):
    depth[v] = depth[parent] + 1 if parent != -1 else 0
    for to in g[v]:
        if to == parent:
            continue
        dfs(to, v, g, depth)
```

**霊夢**: 有向と無向、どう違う？

**魔理沙**: 無向は両方向に追加、有向は片方向だけ。問題文の「一方通行」を見逃すと WA だ。

## 3.6 トポロジカルソート

**霊夢**: 依存関係があるタスクの順番……？

**魔理沙**: **DAG**（有向閉路のないグラフ）で、辺 `u → v` が「u のあと v」なら、**トポロジカル順序** を求める。Kahn 法（入次数 0 をキュー）が定番。

→ [solutions/python/03/topological_sort/](../solutions/python/03/topological_sort/) / [solutions/go/03/topological_sort/](../solutions/go/03/topological_sort/)

```python
from collections import deque

def topological_sort(n, g, indeg):
    q = deque([i for i in range(n) if indeg[i] == 0])
    order = []
    while q:
        v = q.popleft()
        order.append(v)
        for to in g[v]:
            indeg[to] -= 1
            if indeg[to] == 0:
                q.append(to)
    return order if len(order) == n else []  # 空なら閉路あり
```

```go
q := []int{}
for i := 0; i < n; i++ {
    if indeg[i] == 0 {
        q = append(q, i)
    }
}
// BFS 同様に indeg を減らす
```

**霊夢**: 順序が複数あるときは？

**魔理沙**: どれでもよい問題と、辞書順最小など指定がある問題がある。文面を読め。

## 3.7 組み合わせの基礎

**霊夢**: nCr とか、mod で余りを取るやつ？

**魔理沙**: 数え上げが爆発するときは **nCr** を使う。mod 素数 `p` では逆元で割り算する。

#### パスカルの三角形（mod）

→ [solutions/python/03/ncr/](../solutions/python/03/ncr/) / [solutions/go/03/ncr/](../solutions/go/03/ncr/)

```python
MOD = 998244353

def build_nCr(n, mod=MOD):
    c = [[0] * (n + 1) for _ in range(n + 1)]
    c[0][0] = 1
    for i in range(1, n + 1):
        c[i][0] = c[i][i] = 1
        for j in range(1, i):
            c[i][j] = (c[i - 1][j - 1] + c[i - 1][j]) % mod
    return c
```

```go
const mod = 998244353

func buildNCR(n int) [][]int {
    c := make([][]int, n+1)
    for i := 0; i <= n; i++ {
        c[i] = make([]int, n+1)
    }
    c[0][0] = 1
    for i := 1; i <= n; i++ {
        c[i][0], c[i][i] = 1, 1
        for j := 1; j < i; j++ {
            c[i][j] = (c[i-1][j-1] + c[i-1][j]) % mod
        }
    }
    return c
}
```

#### 逆元（フェルマ）

```python
def mod_pow(a, e, mod=MOD):
    res = 1
    while e:
        if e & 1:
            res = res * a % mod
        a = a * a % mod
        e >>= 1
    return res

def mod_inv(a, mod=MOD):
    return mod_pow(a, mod - 2, mod)
```

**魔理沙**: [04.md](04.md) で逆元・組合せを実戦投入する。緑では **パスカルで nCr を取る** ところまででよい。

## 3.8 優先度付きキュー（ダイクストラ入門）

**霊夢**: ヒープって、最小値がすぐ取れるやつ？

**魔理沙**: **優先度付きキュー** で、重み付きグラフの最短距離を求める **ダイクストラ** が ARC A / ABC D の定番だ。

#### ダイクストラ（非負辺）

→ [solutions/python/03/dijkstra/](../solutions/python/03/dijkstra/) / [solutions/go/03/dijkstra/](../solutions/go/03/dijkstra/)

```python
import heapq

def dijkstra(g, start, n):
    INF = 10**18
    dist = [INF] * n
    dist[start] = 0
    pq = [(0, start)]
    while pq:
        d, v = heapq.heappop(pq)
        if d > dist[v]:
            continue
        for to, cost in g[v]:
            nd = d + cost
            if nd < dist[to]:
                dist[to] = nd
                heapq.heappush(pq, (nd, to))
    return dist
```

```go
import (
    "container/heap"
)

type edge struct{ to, cost int }
type item struct{ d, v int }
type pq []item

func (h pq) Len() int            { return len(h) }
func (h pq) Less(i, j int) bool { return h[i].d < h[j].d }
func (h pq) Swap(i, j int)       { h[i], h[j] = h[j], h[i] }
func (h *pq) Push(x interface{})  { *h = append(*h, x.(item)) }
func (h *pq) Pop() interface{} {
    old := *h
    n := len(old)
    x := old[n-1]
    *h = old[:n-1]
    return x
}
```

**霊夢**: 負の辺があるときは？

**魔理沙**: ダイクストラは使えない。ベルマン・フォードやフロイドは水色以降。緑では **非負** だけ覚えろ。
