## 入出力

### 高速入力（推奨）

```python
import sys

input = sys.stdin.readline  # 行単位。末尾に \n が残るので int 化時に注意

def main() -> None:
    n = int(input())
    a = list(map(int, input().split()))
```

### まとめて読む

```python
data = sys.stdin.read().split()
it = iter(data)
n = int(next(it))
```

### 複数行・グリッド

```python
grid = [input().strip() for _ in range(h)]
# または
grid = [list(map(int, input().split())) for _ in range(h)]
```

### 出力

```python
print(x)                    # 末尾改行
print(*row)                 # スペース区切り
print("\n".join(map(str, ans)))
sys.stdout.write(f"{x}\n")  # 大量出力時
```

## 定数・mod

```python
MOD = 10**9 + 7
INF = 10**18

def mod_pow(a, e, mod=MOD):
    return pow(a, e, mod)

def mod_inv(a, mod=MOD):
    return pow(a, mod - 2, mod)
```

## コンテナ（`collections`）

| 型 | 用途 |
|----|------|
| `deque` | BFS、スライディングウィンドウ |
| `Counter` | 頻度、Multiset |
| `defaultdict` | 隣接リスト、集計 |
| `OrderedDict` | LRU 風（最近は通常 `dict` で十分） |

```python
from collections import deque, Counter, defaultdict

q = deque([start])
q.append(x)
q.popleft()

cnt = Counter(a)
g = defaultdict(list)
g[u].append(v)
```

## `heapq`（最小ヒープ）

```python
import heapq

heap = []
heapq.heappush(heap, x)
x = heapq.heappop(heap)
# 最大ヒープ: (-value, item) で push
heapq.heappush(heap, (-dist, v))
```

## `bisect`（二分）

```python
import bisect

a = sorted(xs)
i = bisect.bisect_left(a, x)   # x を挿入する位置（左）
j = bisect.bisect_right(a, x)  # 右
# a[i:j] が x と等しい区間（bisect_left 使用時）
```

## よくあるミス

| 現象 | 原因 | 対策 |
|------|------|------|
| TLE | 遅い `input()` | `readline` / `stdin.read` |
| WA（末尾） | `print` の余計な空白 | `sep` / フォーマット確認 |
| RE | 0 除算・インデックス | 境界・空リスト |
| MLE | 巨大リストの二重保持 | 不要コピー削除 |
