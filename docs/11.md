## 組合せ（逆元テーブル）

実装例: [solutions/python/05/modinv/](../solutions/python/05/modinv/)

### Python（骨格）

```python
MOD = 10**9 + 7
MAX = 200005
fac = [1] * MAX
finv = [1] * MAX
for i in range(2, MAX):
    fac[i] = fac[i - 1] * i % MOD
finv[MAX - 1] = pow(fac[MAX - 1], MOD - 2, MOD)
for i in range(MAX - 2, -1, -1):
    finv[i] = finv[i + 1] * (i + 1) % MOD

def nCr(n, r, mod=MOD):
    if r < 0 or r > n:
        return 0
    return fac[n] * finv[r] % mod * finv[n - r] % mod
```

## Union-Find（DSU）

実装例: [solutions/python/05/dsu/](../solutions/python/05/dsu/)（Part 4）

### Python（骨格）

```python
class DSU:
    def __init__(self, n):
        self.p = list(range(n))
        self.r = [0] * n

    def find(self, x):
        if self.p[x] != x:
            self.p[x] = self.find(self.p[x])
        return self.p[x]

    def unite(self, a, b):
        a, b = self.find(a), self.find(b)
        if a == b:
            return False
        if self.r[a] < self.r[b]:
            a, b = b, a
        self.p[b] = a
        if self.r[a] == self.r[b]:
            self.r[a] += 1
        return True
```

## ダイクストラ

実装例: [solutions/python/04/dijkstra/](../solutions/python/04/dijkstra/)

### Python（骨格）

```python
import heapq

def dijkstra(g, start, n):
    dist = [10**30] * n
    dist[start] = 0
    pq = [(0, start)]
    while pq:
        d, v = heapq.heappop(pq)
        if d > dist[v]:
            continue
        for to, w in g[v]:
            nd = d + w
            if nd < dist[to]:
                dist[to] = nd
                heapq.heappush(pq, (nd, to))
    return dist
```

## Fenwick（BIT）

実装例: [solutions/python/05/fenwick/](../solutions/python/05/fenwick/)

### Python

```python
class Fenwick:
    def __init__(self, n):
        self.n = n
        self.bit = [0] * (n + 1)

    def add(self, i, x):
        i += 1
        while i <= self.n:
            self.bit[i] += x
            i += i & -i

    def sum(self, i):
        i += 1
        s = 0
        while i > 0:
            s += self.bit[i]
            i -= i & -i
        return s
```

## セグメントツリー（区間和）

実装例: [solutions/python/05/segtree/](../solutions/python/05/segtree/)

### Python（骨格）

```python
class SegTree:
    def __init__(self, data):
        n = len(data)
        size = 1
        while size < n:
            size <<= 1
        self.size = size
        self.dat = [0] * (2 * size)
        for i, x in enumerate(data):
            self.dat[size + i] = x
        for i in range(size - 1, 0, -1):
            self.dat[i] = self.dat[i * 2] + self.dat[i * 2 + 1]

    def update(self, i, x):
        i += self.size
        self.dat[i] = x
        while i > 1:
            i //= 2
            self.dat[i] = self.dat[i * 2] + self.dat[i * 2 + 1]

    def query(self, l, r):
        l += self.size
        r += self.size
        res = 0
        while l < r:
            if l & 1:
                res += self.dat[l]
                l += 1
            if r & 1:
                r -= 1
                res += self.dat[r]
            l //= 2
            r //= 2
        return res
```
