## 6.1 高度な DP

**霊夢**: [05.md](05.md) までで DP はたくさんやった。黄色では何が増えるの？

**魔理沙**: **遷移が線形** なら **行列のべき乗**、**Convex Hull Trick（CHT）** で DP を高速化するパターンが増える。

### 行列のべき乗（線形漸化）

`dp[k] = sum(c[j] * dp[k-j])` のような式は、状態をベクトルにして **遷移行列 T** を作り、`T^n` で k ステップ進める。

→ [solutions/python/06/matrix_pow/](../solutions/python/06/matrix_pow/) / [solutions/go/06/matrix_pow/](../solutions/go/06/matrix_pow/)

```python
def mat_mul(A, B, mod):
    n, m, p = len(A), len(B), len(B[0])
    C = [[0] * p for _ in range(n)]
    for i in range(n):
        for k in range(m):
            if A[i][k] == 0:
                continue
            for j in range(p):
                C[i][j] = (C[i][j] + A[i][k] * B[k][j]) % mod
    return C

def mat_pow(M, e, mod):
    n = len(M)
    res = [[1 if i == j else 0 for j in range(n)] for i in range(n)]
    while e:
        if e & 1:
            res = mat_mul(res, M, mod)
        M = mat_mul(M, M, mod)
        e >>= 1
    return res
```

**例: フィボナッチ第 n 項（mod）**

```python
def fib(n, mod=10**9 + 7):
    if n == 0:
        return 0
    T = [[1, 1], [1, 0]]
    Tn = mat_pow(T, n - 1, mod)
    return Tn[0][0]
```

```go
// 2x2 の行列乗算・べき乗を mod で
```

### Convex Hull Trick（入門）

**魔理沙**: DP が `dp[i] = min_j (dp[j] + cost(j, i))` で、`cost` が **傾きが単調** なら、deque で直線群の下包絡を維持して O(N) になる。

→ [solutions/python/06/cht/](../solutions/python/06/cht/) / [solutions/go/06/cht/](../solutions/go/06/cht/)

```python
from collections import deque

def cht_min(lines):
    """lines: (slope m, intercept b) for y = m*x + b"""
    dq = deque()
    def bad(l1, l2, l3):
        return (l2[1] - l1[1]) * (l3[0] - l2[0]) >= (l2[0] - l1[0]) * (l3[1] - l2[1])
    for ln in lines:
        while len(dq) >= 2 and bad(dq[-2], dq[-1], ln):
            dq.pop()
        dq.append(ln)
    return dq
```

**霊夢**: 傾きが単調じゃないと？

**魔理沙**: 別の CHT や Li Chao 木（セグ木）を使う。黄色では **単調傾き** の型を見抜くところまででよい。

## 6.2 木の重心分解・LCA

**霊夢**: 木の「真ん中」って、重心？

**魔理沙**: **重心** は、どの部分木を切っても残りのサイズが n/2 以下になる頂点だ。**重心分解** は、重心で木を分割し、パスクエリを O(log n) 段で処理する技法だ。

### LCA（ダブリング）

→ [solutions/python/06/lca/](../solutions/python/06/lca/) / [solutions/go/06/lca/](../solutions/go/06/lca/)

```python
import sys

sys.setrecursionlimit(10**7)

def dfs(v, p, depth, up, g, LOG):
    up[v][0] = p
    for i in range(1, LOG):
        up[v][i] = up[up[v][i - 1]][i - 1] if up[v][i - 1] != -1 else -1
    for to in g[v]:
        if to == p:
            continue
        depth[to] = depth[v] + 1
        dfs(to, v, depth, up, g, LOG)

def lca(a, b, depth, up, LOG):
    if depth[a] < depth[b]:
        a, b = b, a
    d = depth[a] - depth[b]
    for i in range(LOG):
        if d >> i & 1:
            a = up[a][i]
    if a == b:
        return a
    for i in range(LOG - 1, -1, -1):
        if up[a][i] != up[b][i]:
            a = up[a][i]
            b = up[b][i]
    return up[a][0]
```

```go
// up[v][k] = 2^k 個上の祖先
```

**霊夢**: パス上の和や最大値は？

**魔理沙**: 重心分解 + データ構造、または **HLD（重軽分解）**（橙色で詳しくする）。黄色では **LCA が書ける** ことが先だ。

## 6.3 平方分割

**霊夢**: クエリがたくさん来る配列問題、全部セグ木？

**魔理沙**: **平方分割** や **Mo's algorithm** で、オフラインクエリをまとめて処理する。区間 `[l,r]` のクエリを、**左端の動きが O(√N)** になるよう並べ替える。

### Mo's algorithm（入門）

→ [solutions/python/06/mo/](../solutions/python/06/mo/) / [solutions/go/06/mo/](../solutions/go/06/mo/)

```python
def mo_order(queries, n, block):
    ordered = []
    for idx, (l, r) in enumerate(queries):
        block_id = l // block
        ordered.append((block_id, r if block_id % 2 else -r, l, r, idx))
    ordered.sort()
    return ordered

def mo_count_distinct(a, queries):
    n = len(a)
    block = int(n**0.5) + 1
    order = mo_order(queries, n, block)
    cnt = {}
    cur_l, cur_r = 0, 0
    distinct = 0
    ans = [0] * len(queries)

    def add(i):
        nonlocal distinct
        x = a[i]
        cnt[x] = cnt.get(x, 0) + 1
        if cnt[x] == 1:
            distinct += 1

    def remove(i):
        nonlocal distinct
        x = a[i]
        cnt[x] -= 1
        if cnt[x] == 0:
            distinct -= 1

    for _, _, l, r, idx in order:
        while cur_r <= r:
            add(cur_r)
            cur_r += 1
        while cur_r - 1 > r:
            cur_r -= 1
            remove(cur_r)
        while cur_l > l:
            cur_l -= 1
            add(cur_l)
        while cur_l < l:
            remove(cur_l)
            cur_l += 1
        ans[idx] = distinct
    return ans
```

**魔理沙**: 計算量はだいたい **O((N+Q)√N)**。オフラインで区間の種類数・頻度などに使う。

## 6.4 FFT・NTT（入門）

**霊夢**: 畳み込みって、多項式の掛け算？

**魔理沙**: 配列 `a`, `b` の畳み込み `c` は `c[k] = sum_i a[i]*b[k-i]`。ナイーブは O(N²)。**NTT** は mod 上で O(N log N) だ。競プロでは **998244353** と原根 3 が定番。

### NTT（入門・再帰）

→ [solutions/python/06/ntt/](../solutions/python/06/ntt/) / [solutions/go/06/ntt/](../solutions/go/06/ntt/)

```python
MOD = 998244353
G = 3

def ntt(a, invert=False):
    n = len(a)
    j = 0
    for i in range(1, n):
        bit = n >> 1
        while j & bit:
            j ^= bit
            bit >>= 1
        j ^= bit
        if i < j:
            a[i], a[j] = a[j], a[i]
    length = 2
    while length <= n:
        w = pow(G, (MOD - 1) // length, MOD)
        if invert:
            w = pow(w, MOD - 2, MOD)
        for i in range(0, n, length):
            for j in range(length // 2):
                u = a[i + j]
                v = a[i + j + length // 2] * w % MOD
                a[i + j] = (u + v) % MOD
                a[i + j + length // 2] = (u - v) % MOD
        length <<= 1
    if invert:
        inv_n = pow(n, MOD - 2, MOD)
        for i in range(n):
            a[i] = a[i] * inv_n % MOD
    return a

def convolution(a, b):
    n1, n2 = len(a), len(b)
    n = 1
    while n < n1 + n2 - 1:
        n <<= 1
    fa = a + [0] * (n - n1)
    fb = b + [0] * (n - n2)
    fa = ntt(fa)
    fb = ntt(fb)
    for i in range(n):
        fa[i] = fa[i] * fb[i] % MOD
    return ntt(fa, invert=True)[: n1 + n2 - 1]
```

```go
// mod 998244353, primitive root 3
// 長さを 2 の冪にパディングして NTT
```

**霊夢**: FFT は？

**魔理沙**: 実数の FFT も同型だが、競プロでは **NTT + 整数 mod** が主流。AGC B で多項式・畳み込みが出る。

## 6.6 文字列：サフィックス配列・自動機

**霊夢**: サフィックス配列って、全部の後ろの並びをソートした感じ？

**魔理沙**: **辞書順にサフィックスを並べた配列 SA** と、**LCP（最長共通接頭辞）** の組で、部分文字列・繰り返しを扱う。

### サフィックス配列（簡易構築 O(N log² N)）

→ [solutions/python/06/suffix_array/](../solutions/python/06/suffix_array/) / [solutions/go/06/suffix_array/](../solutions/go/06/suffix_array/)

```python
def suffix_array(s):
    n = len(s)
    sa = list(range(n))
    rank = [ord(c) for c in s]
    k = 1
    while k < n:
        sa.sort(key=lambda i: (rank[i], rank[i + k] if i + k < n else -1))
        new_rank = [0] * n
        new_rank[sa[0]] = 0
        for i in range(1, n):
            a = (rank[sa[i]], rank[sa[i] + k] if sa[i] + k < n else -1)
            b = (rank[sa[i - 1]], rank[sa[i - 1] + k] if sa[i - 1] + k < n else -1)
            new_rank[sa[i]] = new_rank[sa[i - 1]] + (a < b)
        rank = new_rank
        if rank[sa[-1]] == n - 1:
            break
        k <<= 1
    return sa
```

**魔理沙**: 辞書の複数文字列を同時にマッチする **オートマトン**。黄色では「存在する」くらいの理解でよい。実装は [solutions/python/06/aho_corasick/](../solutions/python/06/aho_corasick/) に簡易版を置く。
