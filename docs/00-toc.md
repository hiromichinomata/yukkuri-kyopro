# ゆっくり競プロ — 目次

AtCoder の **ABC / ARC / AGC** を土台に、レーティング帯ごとに必要な知識を **ハンズオン** で身につける本。  
解説は **ゆっくり霊夢** と **ゆっくり魔理沙** の掛け合い形式。コード例・演習の解答は **Python** と **Go** の両方を掲載する。

## リポジトリ構成（予定）

```
docs/
  00-toc.md    # 目次
  01.md … 09.md   # Part 0〜8（本文は各 1 ファイルに集約）
  10.md … 16.md   # 付録
solutions/
  python/{02,03,…}/   # 番号は docs の Part ファイルに対応（02.md → python/02/）
  go/{02,03,…}/
scripts/       # ローカル検証・テンプレ生成（任意）
```

**各 Part ファイル（`02.md` など）の中身の目安**

1. 到達目標・到達チェック  
2. ゆっくり解説（霊夢・魔理沙の対談原稿）  
3. ハンズオン（手順・チェックポイント・推奨問題）  
4. コード例へのリンク（`solutions/python/…`, `solutions/go/…`）  
5. 次のファイルへ（例: `02.md` の末尾 → [03.md](03.md)）

## 進め方の推奨

1. **自分のレーティングの Part から**読む（前の Part は復習用にスキップ可）。  
2. 各章は **📖 → 🖐️ → 🎯** の順。コードは **Python と Go の両方**を見比べる。  
3. **まとめハンズオン**まで終えたら、次の色の Part に進む。  
4. ARC / AGC は **水色以降**で本格的に登場するが、茶色・緑でも **ARC A** など「体験」枠を置く。
