## コンテスト・判定

| 用語 | 意味 |
|------|------|
| ABC / ARC / AGC | AtCoder の難易度帯の異なる定期コンテスト |
| AC | Accepted（正解） |
| WA | Wrong Answer |
| TLE | Time Limit Exceeded |
| RE | Runtime Error |
| 部分点 | 一部テストのみ正解でも得点が付く設計 |
| インタラクティブ問題 | ジャッジと入出力を往復する形式。出力のたびに flush が必要 |
| PyPy | JIT 付きの Python 実装。ループの多いコードが速い |
| ACL | AtCoder Library。公式の C++ ライブラリ（Python には有志の移植あり） |
| ジャッジ | 提出コードを複数テストで実行する仕組み |

## 計算量

| 用語 | 意味 |
|------|------|
| O(…) | 入力サイズに対する計算量のオーダー |
| 定数 | オーダー内の隠れた係数（TLE の原因になりやすい） |
| 全探索 | すべての候補を試す |
| bit 全探索 | 2^N 通りの選び方を整数のビットで列挙する |
| 順列全探索 | N! 通りの並べ方をすべて試す |
| 枝刈り | 探索木で不要な枝を切る |
| 二分探索 | 単調性を利用して解空間を半分ずつ絞る |
