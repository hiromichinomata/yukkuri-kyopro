## 7.1 Meet in the middle

**霊夢**: 指数が 2^40 とか、もう無理でしょ……

**魔理沙**: **Meet in the middle** で、全体 2^N を **2^(N/2) + 2^(N/2)** に割る。N ≤ 40 前後なら現実的になる。

**霊夢**: 半分に割って、前半と後半で会い合う感じ？

**魔理沙**: その通り。全部 2^40 は無理でも、2^20 + 2^20 ならギリギリ現実的だ。メモリも **2^(N/2) 個の整数** を持つので、N/2 は 20〜22 程度が安全ラインになることが多い。

### イメージ / 手順

1. 配列を **前半・後半** に分割（だいたい半分ずつ）  
2. 前半の **全部分和** を列挙してソート（またはハッシュ）  
3. 後半の各和 s について **need = T - s** を前半で探す  
4. 2 集合の組み合わせなら、前半列挙 + 後半列挙 + ハッシュでペアリング

| 場面 | やり方 |
|------|--------|
| 部分和が T | 前半の全部分和を列挙 → 後半で T - sum を二分探索 |
| 2 集合の組 | 前半列挙 + 後半列挙 + ハッシュでペア |
| xor 和が K | 前半の全 xor を map → 後半で K xor s を検索 |

### いつ使うか

| キーワード | 候補 |
|------------|------|
| N ≤ 40、部分集合、2^N が重い | Meet in the middle |
| 部分和・xor 和が T | 同上 |
| N が 20 以下 | 全探索でも可 |
| 順序付き・DP が効く | MITM より DP |

### 計算量

| 処理 | 目安 |
|------|------|
| 部分和列挙（半分） | O(2^(N/2)) |
| ソート + 二分 | O(2^(N/2) log 2^(N/2)) |
| メモリ | O(2^(N/2)) |

### つまずき

- **空集合（和 0）** を列挙に含め忘れる  
- 前半を **ソートせず** 二分探索する  
- N/2 が大きすぎて **メモリ RE**  
- 重複する和の **個数** が問題に効くのに set だけ使う

→ [solutions/python/07/meet_in_middle/](../solutions/python/07/meet_in_middle/) / [solutions/go/07/meet_in_middle/](../solutions/go/07/meet_in_middle/)

```python
import bisect

def subset_sums(xs):
    n = len(xs)
    sums = [0]
    for i in range(n):
        sums = [s + xs[i] for s in sums] + sums
    return sums

def can_make_sum(xs, target):
    n = len(xs)
    mid = n // 2
    left = sorted(subset_sums(xs[:mid]))
    right = subset_sums(xs[mid:])
    for s in right:
        need = target - s
        i = bisect.bisect_left(left, need)
        if i < len(left) and left[i] == need:
            return True
    return False
```

```go
func subsetSums(xs []int) []int {
	sums := []int{0}
	for _, x := range xs {
		next := make([]int, 0, len(sums)*2)
		for _, s := range sums {
			next = append(next, s+x)
		}
		sums = append(next, sums...)
	}
	return sums
}

func canMakeSum(xs []int, target int) bool {
	n := len(xs)
	mid := n / 2
	left := subsetSums(xs[:mid])
	sort.Ints(left)
	right := subsetSums(xs[mid:])
	for _, s := range right {
		need := target - s
		i := sort.SearchInts(left, need)
		if i < len(left) && left[i] == need {
			return true
		}
	}
	return false
}
```

**魔理沙**: 前半の `subsetSums` のあと **必ず sort** する。テンプレの正本は [solutions/go/07/meet_in_middle/](../solutions/go/07/meet_in_middle/) だ。

## 7.2 永続データ構造

**霊夢**: 永続って、過去版のデータ構造も使えるやつ？

**魔理沙**: **更新の履歴を残す** データ構造だ。競プロでよく出るのは **永続セグメントツリー**（過去の配列版への参照）。

### イメージ / 手順

1. 配列の各 **バージョン** ごとにセグ木の根を持つ  
2. 更新するとき、経路上のノードだけ **新規コピー**（`clone`）  
3. 変更しない子は **旧ノードを共有**（メモリ節約）  
4. クエリは「バージョン v の根」から通常のセグ木と同様に descent

### 考え方

- 通常のセグ木は更新でノードを上書き  
- 永続版は **変更ノードだけ新規確保** し、根をバージョンごとに持つ  
- 空間は O((N+Q) log N) 程度  

→ [solutions/python/07/persistent_segtree/](../solutions/python/07/persistent_segtree/) / [solutions/go/07/persistent_segtree/](../solutions/go/07/persistent_segtree/)

```python
class Node:
    __slots__ = ("l", "r", "val", "lazy")

    def __init__(self, val=0):
        self.l = self.r = None
        self.val = val
        self.lazy = 0

def clone(node):
    if node is None:
        return None
    n = Node(node.val)
    n.lazy = node.lazy
    n.l = node.l
    n.r = node.r
    return n

def push(node, l, r):
    if node is None or node.lazy == 0:
        return
    mid = (l + r) // 2
    node.l = clone(node.l)
    node.r = clone(node.r)
    if node.l is None:
        node.l = Node()
    if node.r is None:
        node.r = Node()
    node.l.val += node.lazy
    node.r.val += node.lazy
    node.l.lazy += node.lazy
    node.r.lazy += node.lazy
    node.lazy = 0
```

**霊夢**: 全部自分で書くのはキツい……

**魔理沙**: テンプレを [solutions/](../solutions/python/07/persistent_segtree/) から持て。AGC C では **過去時点の区間和** が典型。

### いつ使うか

| キーワード | 候補 |
|------------|------|
| 過去版の配列、バージョン、履歴 | 永続セグ木 |
| 区間和・区間加算の履歴 | 同上 |
| 現版本だけ | 通常のセグ木（[05.md](05.md)） |

### 計算量

| 操作 | 目安 |
|------|------|
| 更新 1 回 | O(log N) 時間・O(log N) 新ノード |
| 全体空間 | O((N+Q) log N) |

### つまずき

- 更新時に **ノードを上書き** して過去版を壊す  
- `clone` せず子を共有して **lazy が伝播しない**  
- 根の配列 `roots[v]` を **バージョン番号** と対応付け忘れ

```go
func clone(n *node) *node {
	if n == nil {
		return nil
	}
	return &node{l: n.l, r: n.r, val: n.val, lazy: n.lazy}
}

func update(n *node, l, r, idx, delta int) *node {
	n = clone(n)
	if l == r {
		n.val += delta
		return n
	}
	mid := (l + r) / 2
	if idx <= mid {
		n.l = update(n.l, l, mid, idx, delta)
	} else {
		n.r = update(n.r, mid+1, r, idx, delta)
	}
	n.val = val(n.l) + val(n.r)
	return n
}
```

## 7.3 リンクカット木・重軽分解（HLD）

**霊夢**: 木のパスを高速に扱うやつ、黄色の LCA の先？

**魔理沙**: **重軽分解（HLD）** は、木を **重い辺と軽い辺** に分け、パスを O(log² N) 個の区間に分解する。セグ木と組み合わせて **パス上の和・最大** などを処理する。

**霊夢**: [06.md](06.md) の LCA との違いは？

**魔理沙**: LCA は **2 点の関係** が中心。HLD は **パス全体** を配列上の連続区間の組に落とす。橙色 ARC E では HLD + セグ木が定番。LCA は HLD の補助にも使う（異なる head 間は LCA で繋ぐ）。

### LCA（復習）と HLD の役割分担

| 目的 | 典型 |
|------|------|
| 2 点の距離・LCA 頂点 | ダブリング（[06.md](06.md) 6.2） |
| パス上の和・max・更新 | HLD + セグ木 |
| 部分木クエリ | DFS 順 + セグ木（in/out） |
| 動的 link/cut | LCT（テンプレ保有） |

### HLD のイメージ / 手順

1. DFS で `size`, `parent`, `depth` を求める  
2. 各頂点の **重い子**（部分木サイズ最大）を選び、同じ `head`（重鎖の先頭）に並べる  
3. `pos[v]` で線形化し、重鎖上は **連続区間** になる  
4. パス u–v を、「head が一致するまで上に登る」ループで **O(log N) 区間** に分解  
5. 各区間をセグ木でクエリ

### いつ使うか

| キーワード | 候補 |
|------------|------|
| 木のパス和・パス max | HLD |
| 木の頂点更新 + パスクエリ | HLD + セグ木 |
| 2 点だけ・距離だけ | LCA |
| 動的に辺追加削除 | LCT |

### 計算量

| 操作 | 目安 |
|------|------|
| 前処理 | O(N) |
| パスクエリ 1 回 | O(log² N)（セグ木 log × 重鎖 log） |

### つまずき

- **軽い辺** の子で新しい `head` を立て忘れる  
- `pos` の DFS 順とセグ木の区間が **ずれる**  
- 根の扱い・1 頂点木で **空クエリ**  
- LCA と HLD を **同じ問題で二重実装** して混乱

→ [solutions/python/07/hld/](../solutions/python/07/hld/) / [solutions/go/07/hld/](../solutions/go/07/hld/)  
→ LCA 復習: [solutions/python/06/lca/](../solutions/python/06/lca/)

```python
def dfs_size(v, p, g, size, parent):
    size[v] = 1
    parent[v] = p
    for to in g[v]:
        if to == p:
            continue
        dfs_size(to, v, g, size, parent)
        size[v] += size[to]

def dfs_hld(v, p, g, size, parent, depth, head, pos, cur):
    head[v] = head[v] if head[v] != -1 else v
    pos[v] = cur[0]
    cur[0] += 1
    heavy = -1
    for to in g[v]:
        if to == p:
            continue
        if heavy == -1 or size[to] > size[heavy]:
            heavy = to
    if heavy != -1:
        head[heavy] = head[v]
        dfs_hld(heavy, v, g, size, parent, depth, head, pos, cur)
    for to in g[v]:
        if to != p and to != heavy:
            dfs_hld(to, v, g, size, parent, depth, head, pos, cur)
```

**リンクカット木（LCT）** は動的な link/cut に強いが、実装は長い。橙色では **HLD + セグ木** を優先し、LCT はテンプレ保有程度でよい。

```go
func dfsHLD(v, p int, g [][]int, size, parent, depth, head, pos []int, cur *int) {
	head[v] = head[v]
	if head[v] == 0 && v != 0 {
		head[v] = v
	}
	pos[v] = *cur
	*cur++
	heavy := -1
	for _, to := range g[v] {
		if to == p {
			continue
		}
		if heavy == -1 || size[to] > size[heavy] {
			heavy = to
		}
	}
	if heavy != -1 {
		head[heavy] = head[v]
		dfsHLD(heavy, v, g, size, parent, depth, head, pos, cur)
	}
	for _, to := range g[v] {
		if to != p && to != heavy {
			head[to] = to
			dfsHLD(to, v, g, size, parent, depth, head, pos, cur)
		}
	}
}
```

**霊夢**: `head` 配列、最初 -1 で埋めるの？

**魔理沙**: 実装では「未設定なら自分を head にする」分岐が多い。テンプレは [solutions/go/07/hld/](../solutions/go/07/hld/) をそのまま使え。

### ガウス消去（mod）

→ [solutions/python/07/gauss/](../solutions/python/07/gauss/) / [solutions/go/07/gauss/](../solutions/go/07/gauss/)

```python
def gauss(A, mod, eps=10**9 + 7):
    """A: n x m 拡大係数行列、解または None"""
    n = len(A)
    m = len(A[0])
    row = 0
    for col in range(m - 1):
        pivot = -1
        for r in range(row, n):
            if A[r][col] % mod != 0:
                pivot = r
                break
        if pivot == -1:
            continue
        A[row], A[pivot] = A[pivot], A[row]
        inv = pow(A[row][col], mod - 2, mod)
        for c in range(col, m):
            A[row][c] = A[row][c] * inv % mod
        for r in range(n):
            if r == row:
                continue
            factor = A[r][col]
            if factor == 0:
                continue
            for c in range(col, m):
                A[r][c] = (A[r][c] - factor * A[row][c]) % mod
        row += 1
    return A
```

```go
func gauss(A [][]int, mod int) [][]int {
	n, m := len(A), len(A[0])
	row := 0
	for col := 0; col < m-1; col++ {
		pivot := -1
		for r := row; r < n; r++ {
			if A[r][col]%mod != 0 {
				pivot = r
				break
			}
		}
		if pivot == -1 {
			continue
		}
		A[row], A[pivot] = A[pivot], A[row]
		inv := 1
		base := A[row][col] % mod
		for e := mod - 2; e > 0; e >>= 1 {
			if e&1 == 1 {
				inv = inv * base % mod
			}
			base = base * base % mod
		}
		for c := col; c < m; c++ {
			A[row][c] = A[row][c] * inv % mod
		}
		for r := 0; r < n; r++ {
			if r == row {
				continue
			}
			factor := A[r][col]
			if factor == 0 {
				continue
			}
			for c := col; c < m; c++ {
				A[r][c] = (A[r][c] - factor*A[row][c]%mod + mod) % mod
			}
		}
		row++
	}
	return A
}
```

### ガウス・xor の計算量とつまずき

| 処理 | 目安 |
|------|------|
| ガウス（n×m） | O(n²m) 程度 |
| xor 基底 add | O(log V)（V=値のビット幅） |

- **mod が素数でない** と逆元が無い列がある  
- xor 基底で **最大 xor** は高位ビットから貪欲  
- ガウスと xor を **同じ問題で取り違え**（xor は XOR 専用）

### xor 基底

→ [solutions/python/07/xor_basis/](../solutions/python/07/xor_basis/) / [solutions/go/07/xor_basis/](../solutions/go/07/xor_basis/)

```python
class XorBasis:
    def __init__(self, bits=60):
        self.b = [0] * bits

    def add(self, x):
        for i in range(len(self.b) - 1, -1, -1):
            if x >> i & 1 == 0:
                continue
            if self.b[i] == 0:
                self.b[i] = x
                return True
            x ^= self.b[i]
        return False

    def max_xor(self):
        x = 0
        for i in range(len(self.b) - 1, -1, -1):
            if self.b[i] and (x >> i & 1) == 0:
                x ^= self.b[i]
        return x
```

```go
type XorBasis struct {
	b []int
}

func (xb *XorBasis) Add(x int) bool {
	for i := len(xb.b) - 1; i >= 0; i-- {
		if x>>i&1 == 0 {
			continue
		}
		if xb.b[i] == 0 {
			xb.b[i] = x
			return true
		}
		x ^= xb.b[i]
	}
	return false
}

func (xb *XorBasis) MaxXor() int {
	x := 0
	for i := len(xb.b) - 1; i >= 0; i-- {
		if xb.b[i] != 0 && x>>i&1 == 0 {
			x ^= xb.b[i]
		}
	}
	return x
}
```

## 7.5 幾何（応用）

**霊夢**: [05.md](05.md) の凸包の先？

**魔理沙**: **最近点対**、**円と直線**、**半平面交** など。橙色 ARC E では **実装の堅牢さ**（整数、倍精度の誤差）が問われる。

**霊夢**: 浮動小数、怖い……

**魔理沙**: 座標が整数なら **距離の二乗** で比較し、sqrt を避ける。最近点対は分割統治法で O(n log n)。半平面交は角度ソート + deque だが、まず [05.md](05.md) の CCW・凸包を復習してから触れ。

### いつ使うか

| キーワード | 候補 |
|------------|------|
| 最近点、最小距離 | 最近点対 |
| 円・内側・接触 | 距離二乗 |
| 半平面・交領域 | 半平面交（テンプレ） |
| 凸包・外側 | [05.md](05.md) |

### 計算量

| 問題 | 目安 |
|------|------|
| 最近点対 | O(n log n) |
| 全対比較 | O(n²)（n 小さいとき） |

### つまずき

- sqrt 比較で **誤差 WA**  
- strip 内の **8 点チェック** を省略  
- 座標圧縮と **ソート順** の取り違え

### 最近点対（分割統治法）

→ [solutions/python/07/closest_pair/](../solutions/python/07/closest_pair/) / [solutions/go/07/closest_pair/](../solutions/go/07/closest_pair/)

```python
def dist2(a, b):
    return (a[0] - b[0]) ** 2 + (a[1] - b[1]) ** 2

def closest_pair(points):
    points = sorted(points)
    n = len(points)
    if n <= 1:
        return 0

    def solve(l, r):
        if r - l <= 3:
            best = 10**30
            for i in range(l, r):
                for j in range(i + 1, r):
                    best = min(best, dist2(points[i], points[j]))
            return best
        mid = (l + r) // 2
        midx = points[mid][0]
        d = min(solve(l, mid), solve(mid, r))
        strip = [p for p in points[l:r] if (p[0] - midx) ** 2 < d]
        strip.sort(key=lambda p: p[1])
        for i in range(len(strip)):
            for j in range(i + 1, min(i + 8, len(strip))):
                d = min(d, dist2(strip[i], strip[j]))
        return d

    return solve(0, n)
```

```go
func dist2(a, b [2]int) int {
	dx := a[0] - b[0]
	dy := a[1] - b[1]
	return dx*dx + dy*dy
}

func closestPair(points [][2]int) int {
	sort.Slice(points, func(i, j int) bool {
		return points[i][0] < points[j][0]
	})
	n := len(points)
	var solve func(l, r int) int
	solve = func(l, r int) int {
		if r-l <= 3 {
			best := 1 << 60
			for i := l; i < r; i++ {
				for j := i + 1; j < r; j++ {
					if d := dist2(points[i], points[j]); d < best {
						best = d
					}
				}
			}
			return best
		}
		mid := (l + r) / 2
		midx := points[mid][0]
		d := solve(l, mid)
		if r2 := solve(mid, r); r2 < d {
			d = r2
		}
		var strip [][2]int
		for _, p := range points[l:r] {
			dx := p[0] - midx
			if dx*dx < d {
				strip = append(strip, p)
			}
		}
		sort.Slice(strip, func(i, j int) bool { return strip[i][1] < strip[j][1] })
		for i := 0; i < len(strip); i++ {
			for j := i + 1; j < len(strip) && j < i+8; j++ {
				if dd := dist2(strip[i], strip[j]); dd < d {
					d = dd
				}
			}
		}
		return d
	}
	return solve(0, n)
}
```

## 7.6 グラフ：強連結成分・2-SAT

**霊夢**: 有向グラフの「まとまり」？

**魔理沙**: **強連結成分（SCC）** は、互いに行き来できる頂点の塊。DAG に縮約してから DP するパターンが多い。

**霊夢**: 縮約って、塊を 1 頂点に潰すやつ？

**魔理沙**: そう。SCC ごとに代表頂点を置くと **DAG** になる。トポロジカル順 + DP が使える。2-SAT は「論理の依存」を有向グラフにしたあと SCC で判定する。

### いつ使うか（SCC / 2-SAT）

| キーワード | 候補 |
|------------|------|
| 有向グラフの閉路・依存 | SCC |
| 2-CNF、制約、割当の可否 | 2-SAT |
| 到達可能性の塊 | SCC |

### Kosaraju（2 回 DFS）

→ [solutions/python/07/scc/](../solutions/python/07/scc/) / [solutions/go/07/scc/](../solutions/go/07/scc/)

```python
def scc(g, n):
    order = []
    seen = [False] * n

    def dfs(v):
        seen[v] = True
        for to in g[v]:
            if not seen[to]:
                dfs(to)
        order.append(v)

    for i in range(n):
        if not seen[i]:
            dfs(i)

    rg = [[] for _ in range(n)]
    for v in range(n):
        for to in g[v]:
            rg[to].append(v)

    comp = [-1] * n
    cid = 0
    seen = [False] * n

    def rdfs(v):
        seen[v] = True
        comp[v] = cid
        for to in rg[v]:
            if not seen[to]:
                rdfs(to)

    for v in reversed(order):
        if not seen[v]:
            rdfs(v)
            cid += 1
    return comp, cid
```

```go
func sccGo(g [][]int, n int) ([]int, int) {
	order := []int{}
	seen := make([]bool, n)
	var dfs func(v int)
	dfs = func(v int) {
		seen[v] = true
		for _, to := range g[v] {
			if !seen[to] {
				dfs(to)
			}
		}
		order = append(order, v)
	}
	for i := 0; i < n; i++ {
		if !seen[i] {
			dfs(i)
		}
	}
	rg := make([][]int, n)
	for v := 0; v < n; v++ {
		for _, to := range g[v] {
			rg[to] = append(rg[to], v)
		}
	}
	comp := make([]int, n)
	cid := 0
	seen = make([]bool, n)
	var rdfs func(v int)
	rdfs = func(v int) {
		seen[v] = true
		comp[v] = cid
		for _, to := range rg[v] {
			if !seen[to] {
				rdfs(to)
			}
		}
	}
	for i := len(order) - 1; i >= 0; i-- {
		v := order[i]
		if !seen[v] {
			rdfs(v)
			cid++
		}
	}
	return comp, cid
}
```

def add_implication(g, a, b, n_vars):
    # a -> b : a が真なら b も真。頂点 2*n_vars

def sat2_solvable(g, n_vars):
    n = 2 * n_vars
    comp, _ = scc(g, n)
    for i in range(n_vars):
        if comp[2 * i] == comp[2 * i + 1]:
            return False
    return True

## 7.7 高速フーリエ変換・数論（応用）

**霊夢**: [06.md](06.md) の NTT の先？

**魔理沙**: **原根**・**離散対数** が、指数や累乗の方程式に出る。

**霊夢**: NTT は 06 でやったけど、橙色では何が増えるの？

**魔理沙**: **mod が NTT 非対応** のときの CRT、**畳み込みの応用**（生成関数の積）、そして **離散対数** だ。NTT 本体は [06.md](06.md) 6.4 の `convolution` をそのまま使え。

### NTT（復習）と Mo（区間）

| 技法 | 橙色での位置づけ |
|------|------------------|
| NTT | 多項式・組合せ数列（06 テンプレ継続） |
| Mo | オフライン区間・[06.md](06.md) 6.3 |
| BSGS | 離散対数（本節） |

→ Mo: [solutions/python/06/mo/](../solutions/python/06/mo/) / [solutions/go/06/mo/](../solutions/go/06/mo/)  
→ NTT: [solutions/python/06/ntt/](../solutions/python/06/ntt/)

### 離散対数のイメージ / 手順

1. `a^x ≡ b (mod p)` を求める（p 素数など）  
2. 次数 m を決める（例: p-1）  
3. **baby-step**: `a^j` を table 化（j ≈ √m）  
4. **giant-step**: `b * (a^{-√m})^i` が table にあるか確認

### いつ使うか

| キーワード | 候補 |
|------------|------|
| `a^x mod p`、指数 | BSGS / ポーランド法 |
| 原根、次数 | 数論 + 離散対数 |
| 畳み込み | NTT |

### 計算量

| 処理 | 目安 |
|------|------|
| BSGS | O(√m) 時間・空間 |
| NTT | O(N log N) |

### つまずき

- baby テーブルに **a^0=1** を入れ忘れ  
- `a` と `p` が非素数で **逆元がない**  
- NTT の mod と問題の mod が **不一致** のまま畳み込む

### 離散対数（BSGS 入門）

a^x ≡ b (mod p)、x を求める。p が素数、群の次数が分かるとき。

→ [solutions/python/07/discrete_log/](../solutions/python/07/discrete_log/) / [solutions/go/07/discrete_log/](../solutions/go/07/discrete_log/)

```python
def bsgs(a, b, p, m):
    """a^x = b (mod p), 0 <= x < m。存在しなければ -1"""
    a %= p
    b %= p
    step = int(m**0.5) + 1
    baby = {1: 0}
    cur = 1
    for j in range(1, step + 1):
        cur = cur * a % p
        if cur not in baby:
            baby[cur] = j
    factor = pow(a, step * (p - 2), p)
    gamma = b
    for i in range(step + 1):
        if gamma in baby:
            return i * step + baby[gamma]
        gamma = gamma * factor % p
    return -1
```

```go
func powMod(a, e, p int) int {
	res := 1
	a %= p
	for e > 0 {
		if e&1 == 1 {
			res = res * a % p
		}
		a = a * a % p
		e >>= 1
	}
	return res
}

func bsgs(a, b, p, m int) int {
	a %= p
	b %= p
	step := int(math.Sqrt(float64(m))) + 1
	baby := map[int]int{1: 0}
	cur := 1
	for j := 1; j <= step; j++ {
		cur = cur * a % p
		if _, ok := baby[cur]; !ok {
			baby[cur] = j
		}
	}
	factor := powMod(a, step*(p-2), p)
	gamma := b
	for i := 0; i <= step; i++ {
		if j, ok := baby[gamma]; ok {
			return i*step + j
		}
		gamma = gamma * factor % p
	}
	return -1
}
```

**原根**: mod p の乗法群を生成する g。NTT の G=3 は mod 998244353 の原根の一例。

**魔理沙**: どちらも「配列・数列を別の形に変換して答える」系だ。問題文のキーワードで切り分けろ。
