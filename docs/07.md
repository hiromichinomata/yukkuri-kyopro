## 7.1 Meet in the middle

**霊夢**: 指数が 2^40 とか、もう無理でしょ……

**魔理沙**: **Meet in the middle** で、全体 2^N を **2^(N/2) + 2^(N/2)** に割る。N ≤ 40 前後なら現実的になる。

**霊夢**: 半分に割って、前半と後半で会い合う感じ？

**魔理沙**: その通り。全部 2^40 は無理でも、2^20 + 2^20 ならギリギリ現実的だ。メモリも **2^(N/2) 個の整数** を持つので、N/2 は 20〜22 程度が安全ラインになることが多い。

### イメージ / 手順

1. 配列を **前半・後半** に分割（だいたい半分ずつ）  
2. 前半の **全部分和** を列挙してソート（またはハッシュ）  
3. 後半の各和 s について **need = T - s** を前半で探す  
4. 2 集合の組み合わせなら、前半列挙 + 後半列挙 + ハッシュでペアリング

| 場面 | やり方 |
|------|--------|
| 部分和が T | 前半の全部分和を列挙 → 後半で T - sum を二分探索 |
| 2 集合の組 | 前半列挙 + 後半列挙 + ハッシュでペア |
| xor 和が K | 前半の全 xor を map → 後半で K xor s を検索 |

### いつ使うか

| キーワード | 候補 |
|------------|------|
| N ≤ 40、部分集合、2^N が重い | Meet in the middle |
| 部分和・xor 和が T | 同上 |
| N が 20 以下 | 全探索でも可 |
| 順序付き・DP が効く | MITM より DP |

### 計算量

| 処理 | 目安 |
|------|------|
| 部分和列挙（半分） | O(2^(N/2)) |
| ソート + 二分 | O(2^(N/2) log 2^(N/2)) |
| メモリ | O(2^(N/2)) |

### つまずき

- **空集合（和 0）** を列挙に含め忘れる  
- 前半を **ソートせず** 二分探索する  
- N/2 が大きすぎて **メモリ RE**  
- 重複する和の **個数** が問題に効くのに set だけ使う

→ [solutions/python/07/meet_in_middle/](../solutions/python/07/meet_in_middle/) / [solutions/go/07/meet_in_middle/](../solutions/go/07/meet_in_middle/)

```python
import bisect

def subset_sums(xs):
    n = len(xs)
    sums = [0]
    for i in range(n):
        sums = [s + xs[i] for s in sums] + sums
    return sums

def can_make_sum(xs, target):
    n = len(xs)
    mid = n // 2
    left = sorted(subset_sums(xs[:mid]))
    right = subset_sums(xs[mid:])
    for s in right:
        need = target - s
        i = bisect.bisect_left(left, need)
        if i < len(left) and left[i] == need:
            return True
    return False
```

```go
func subsetSums(xs []int) []int {
	sums := []int{0}
	for _, x := range xs {
		next := make([]int, 0, len(sums)*2)
		for _, s := range sums {
			next = append(next, s+x)
		}
		sums = append(next, sums...)
	}
	return sums
}

func canMakeSum(xs []int, target int) bool {
	n := len(xs)
	mid := n / 2
	left := subsetSums(xs[:mid])
	sort.Ints(left)
	right := subsetSums(xs[mid:])
	for _, s := range right {
		need := target - s
		i := sort.SearchInts(left, need)
		if i < len(left) && left[i] == need {
			return true
		}
	}
	return false
}
```

## 7.2 永続データ構造

**霊夢**: 永続って、過去版のデータ構造も使えるやつ？

**魔理沙**: **更新の履歴を残す** データ構造だ。競プロでよく出るのは **永続セグメントツリー**（過去の配列版への参照）。

### イメージ / 手順

1. 配列の各 **バージョン** ごとにセグ木の根を持つ  
2. 更新するとき、経路上のノードだけ **新規コピー**（`clone`）  
3. 変更しない子は **旧ノードを共有**（メモリ節約）  
4. クエリは「バージョン v の根」から通常のセグ木と同様に descent

### 考え方

- 通常のセグ木は更新でノードを上書き  
- 永続版は **変更ノードだけ新規確保** し、根をバージョンごとに持つ  
- 空間は O((N+Q) log N) 程度  

→ [solutions/python/07/persistent_segtree/](../solutions/python/07/persistent_segtree/) / [solutions/go/07/persistent_segtree/](../solutions/go/07/persistent_segtree/)

```python
class Node:
    __slots__ = ("l", "r", "val", "lazy")

    def __init__(self, val=0):
        self.l = self.r = None
        self.val = val
        self.lazy = 0

def clone(node):
    if node is None:
        return None
    n = Node(node.val)
    n.lazy = node.lazy
    n.l = node.l
    n.r = node.r
    return n

def push(node, l, r):
    if node is None or node.lazy == 0:
        return
    mid = (l + r) // 2
    node.l = clone(node.l)
    node.r = clone(node.r)
    if node.l is None:
        node.l = Node()
    if node.r is None:
        node.r = Node()
    node.l.val += node.lazy
    node.r.val += node.lazy
    node.l.lazy += node.lazy
    node.r.lazy += node.lazy
    node.lazy = 0
```

**霊夢**: 全部自分で書くのはキツい……

**魔理沙**: テンプレを [solutions/](../solutions/python/07/persistent_segtree/) から持て。AGC C では **過去時点の区間和** が典型。

### いつ使うか

| キーワード | 候補 |
|------------|------|
| 過去版の配列、バージョン、履歴 | 永続セグ木 |
| 区間和・区間加算の履歴 | 同上 |
| 現版本だけ | 通常のセグ木（[05.md](05.md)） |

### 計算量

| 操作 | 目安 |
|------|------|
| 更新 1 回 | O(log N) 時間・O(log N) 新ノード |
| 全体空間 | O((N+Q) log N) |

### つまずき

- 更新時に **ノードを上書き** して過去版を壊す（必ず `clone` してから書き換える）  
- 遅延伝播つきにするときは、`clone` で **lazy もコピー** しないと過去版と値がずれる  
- 根の配列 `roots[v]` を **バージョン番号** と対応付け忘れ

→ [solutions/python/07/persistent_segtree/](../solutions/python/07/persistent_segtree/) / [solutions/go/07/persistent_segtree/](../solutions/go/07/persistent_segtree/)

```go
type node struct {
	l, r *node
	val  int
}

func clone(n *node) *node {
	if n == nil {
		return nil
	}
	return &node{l: n.l, r: n.r, val: n.val}
}

func val(n *node) int {
	if n == nil {
		return 0
	}
	return n.val
}

func update(n *node, l, r, idx, delta int) *node {
	n = clone(n)
	if l == r {
		n.val += delta
		return n
	}
	mid := (l + r) / 2
	if idx <= mid {
		n.l = update(n.l, l, mid, idx, delta)
	} else {
		n.r = update(n.r, mid+1, r, idx, delta)
	}
	n.val = val(n.l) + val(n.r)
	return n
}
```

## 7.3 リンクカット木・重軽分解（HLD）

**霊夢**: 木のパスを高速に扱うやつ、黄色の LCA の先？

**魔理沙**: **重軽分解（HLD）** は、木を **重い辺と軽い辺** に分け、パスを O(log² N) 個の区間に分解する。セグ木と組み合わせて **パス上の和・最大** などを処理する。

**霊夢**: [06.md](06.md) の LCA との違いは？

**魔理沙**: LCA は **2 点の関係** が中心。HLD は **パス全体** を配列上の連続区間の組に落とす。橙色 ARC E では HLD + セグ木が定番。LCA は HLD の補助にも使う（異なる head 間は LCA で繋ぐ）。

### LCA（復習）と HLD の役割分担

| 目的 | 典型 |
|------|------|
| 2 点の距離・LCA 頂点 | ダブリング（[06.md](06.md) 6.2） |
| パス上の和・max・更新 | HLD + セグ木 |
| 部分木クエリ | DFS 順 + セグ木（in/out） |
| 動的 link/cut | LCT（テンプレ保有） |

### HLD のイメージ / 手順

1. DFS で `size`, `parent`, `depth` を求める  
2. 各頂点の **重い子**（部分木サイズ最大）を選び、同じ `head`（重鎖の先頭）に並べる  
3. `pos[v]` で線形化し、重鎖上は **連続区間** になる  
4. パス u–v を、「head が一致するまで上に登る」ループで **O(log N) 区間** に分解  
5. 各区間をセグ木でクエリ

### いつ使うか

| キーワード | 候補 |
|------------|------|
| 木のパス和・パス max | HLD |
| 木の頂点更新 + パスクエリ | HLD + セグ木 |
| 2 点だけ・距離だけ | LCA |
| 動的に辺追加削除 | LCT |

### 計算量

| 操作 | 目安 |
|------|------|
| 前処理 | O(N) |
| パスクエリ 1 回 | O(log² N)（セグ木 log × 重鎖 log） |

### つまずき

- **軽い辺** の子で新しい `head` を立て忘れる  
- `pos` の DFS 順とセグ木の区間が **ずれる**  
- 根の扱い・1 頂点木で **空クエリ**  
- LCA と HLD を **同じ問題で二重実装** して混乱

→ [solutions/python/07/hld/](../solutions/python/07/hld/) / [solutions/go/07/hld/](../solutions/go/07/hld/)  
→ LCA 復習: [solutions/python/06/lca/](../solutions/python/06/lca/)

```python
def dfs_size(v, p, g, size, parent, depth):
    size[v] = 1
    parent[v] = p
    for to in g[v]:
        if to == p:
            continue
        depth[to] = depth[v] + 1
        dfs_size(to, v, g, size, parent, depth)
        size[v] += size[to]

def dfs_hld(v, p, h, g, size, head, pos, cur):
    """h: v が属する重い鎖の先頭。pos: 鎖が連続するように振った番号"""
    head[v] = h
    pos[v] = cur[0]
    cur[0] += 1
    heavy = -1
    for to in g[v]:
        if to == p:
            continue
        if heavy == -1 or size[to] > size[heavy]:
            heavy = to
    if heavy != -1:
        dfs_hld(heavy, v, h, g, size, head, pos, cur)  # 重い子は同じ鎖
    for to in g[v]:
        if to != p and to != heavy:
            dfs_hld(to, v, to, g, size, head, pos, cur)  # 軽い子は新しい鎖の先頭

def build_hld(g, root=0):
    n = len(g)
    size, parent, depth = [0] * n, [-1] * n, [0] * n
    head, pos = [0] * n, [0] * n
    dfs_size(root, -1, g, size, parent, depth)
    dfs_hld(root, -1, root, g, size, head, pos, [0])
    return parent, depth, head, pos

def hld_lca(a, b, parent, depth, head):
    while head[a] != head[b]:  # 鎖の先頭が深い方を、鎖ごと飛ばして上げる
        if depth[head[a]] > depth[head[b]]:
            a = parent[head[a]]
        else:
            b = parent[head[b]]
    return a if depth[a] < depth[b] else b
```

**リンクカット木（LCT）** は動的な link/cut に強いが、実装は長い。橙色では **HLD + セグ木** を優先し、LCT はテンプレ保有程度でよい。

```go
// dfsHLD: h は v が属する重い鎖の先頭。pos は鎖が連続するように振った番号
func dfsHLD(v, p, h int, g [][]int, size, head, pos []int, cur *int) {
	head[v] = h
	pos[v] = *cur
	*cur++
	heavy := -1
	for _, to := range g[v] {
		if to == p {
			continue
		}
		if heavy == -1 || size[to] > size[heavy] {
			heavy = to
		}
	}
	if heavy != -1 {
		dfsHLD(heavy, v, h, g, size, head, pos, cur) // 重い子は同じ鎖
	}
	for _, to := range g[v] {
		if to != p && to != heavy {
			dfsHLD(to, v, to, g, size, head, pos, cur) // 軽い子は新しい鎖の先頭
		}
	}
}
```

**霊夢**: `head` って、どうやって決めてるの？

**魔理沙**: 引数 `h` で「いまの鎖の先頭」を渡している。重い子には同じ `h` を、軽い子には **自分自身** を渡すので、軽い子から新しい鎖が始まる。LCA は「鎖の先頭が深い方を、鎖ごと親へ飛ばす」を先頭がそろうまで繰り返す。テンプレは [solutions/go/07/hld/](../solutions/go/07/hld/) をそのまま使え。

### ガウス消去（mod）

→ [solutions/python/07/gauss/](../solutions/python/07/gauss/) / [solutions/go/07/gauss/](../solutions/go/07/gauss/)

```python
def gauss(A, mod=10**9 + 7):
    """A: n x m の拡大係数行列。掃き出した後の行列を返す（各ピボット列は 1 が 1 つだけ）"""
    n = len(A)
    m = len(A[0])
    row = 0
    for col in range(m - 1):
        pivot = -1
        for r in range(row, n):
            if A[r][col] % mod != 0:
                pivot = r
                break
        if pivot == -1:
            continue
        A[row], A[pivot] = A[pivot], A[row]
        inv = pow(A[row][col], mod - 2, mod)
        for c in range(col, m):
            A[row][c] = A[row][c] * inv % mod
        for r in range(n):
            if r == row:
                continue
            factor = A[r][col]
            if factor == 0:
                continue
            for c in range(col, m):
                A[r][c] = (A[r][c] - factor * A[row][c]) % mod
        row += 1
    return A
```

```go
const mod = 1_000_000_007

func gauss(A [][]int) [][]int {
	n := len(A)
	m := len(A[0])
	row := 0
	for col := 0; col < m-1; col++ {
		pivot := -1
		for r := row; r < n; r++ {
			if A[r][col]%mod != 0 {
				pivot = r
				break
			}
		}
		if pivot == -1 {
			continue
		}
		A[row], A[pivot] = A[pivot], A[row]
		inv := powMod(A[row][col], mod-2)
		for c := col; c < m; c++ {
			A[row][c] = A[row][c] * inv % mod
		}
		for r := 0; r < n; r++ {
			if r == row {
				continue
			}
			factor := A[r][col]
			if factor == 0 {
				continue
			}
			for c := col; c < m; c++ {
				A[r][c] = (A[r][c] - factor*A[row][c]%mod + mod) % mod
			}
		}
		row++
	}
	return A
}

func powMod(a, e int) int {
	res := 1
	a %= mod
	for e > 0 {
		if e&1 == 1 {
			res = res * a % mod
		}
		a = a * a % mod
		e >>= 1
	}
	return res
}
```

### ガウス・xor の計算量とつまずき

| 処理 | 目安 |
|------|------|
| ガウス（n×m） | O(n²m) 程度 |
| xor 基底 add | O(log V)（V=値のビット幅） |

- **mod が素数でない** と逆元が無い列がある  
- xor 基底で **最大 xor** は高位ビットから貪欲  
- ガウスと xor を **同じ問題で取り違え**（xor は XOR 専用）

### xor 基底

→ [solutions/python/07/xor_basis/](../solutions/python/07/xor_basis/) / [solutions/go/07/xor_basis/](../solutions/go/07/xor_basis/)

```python
class XorBasis:
    def __init__(self, bits=60):
        self.b = [0] * bits

    def add(self, x):
        for i in range(len(self.b) - 1, -1, -1):
            if x >> i & 1 == 0:
                continue
            if self.b[i] == 0:
                self.b[i] = x
                return True
            x ^= self.b[i]
        return False

    def max_xor(self):
        x = 0
        for i in range(len(self.b) - 1, -1, -1):
            if self.b[i] and (x >> i & 1) == 0:
                x ^= self.b[i]
        return x
```

```go
type XorBasis struct {
	b []int
}

func (x *XorBasis) Add(v int) bool {
	for i := len(x.b) - 1; i >= 0; i-- {
		if (v>>i)&1 == 0 {
			continue
		}
		if x.b[i] == 0 {
			x.b[i] = v
			return true
		}
		v ^= x.b[i]
	}
	return false
}

func (x *XorBasis) MaxXor() int {
	res := 0
	for i := len(x.b) - 1; i >= 0; i-- {
		if x.b[i] != 0 && (res>>i)&1 == 0 {
			res ^= x.b[i]
		}
	}
	return res
}
```

## 7.5 幾何（応用）

**霊夢**: [05.md](05.md) の凸包の先？

**魔理沙**: **最近点対**、**円と直線**、**半平面交** など。橙色 ARC E では **実装の堅牢さ**（整数、倍精度の誤差）が問われる。

**霊夢**: 浮動小数、怖い……

**魔理沙**: 座標が整数なら **距離の二乗** で比較し、sqrt を避ける。最近点対は分割統治法で O(n log n)。半平面交は角度ソート + deque だが、まず [05.md](05.md) の CCW・凸包を復習してから触れ。

### いつ使うか

| キーワード | 候補 |
|------------|------|
| 最近点、最小距離 | 最近点対 |
| 円・内側・接触 | 距離二乗 |
| 半平面・交領域 | 半平面交（テンプレ） |
| 凸包・外側 | [05.md](05.md) |

### 計算量

| 問題 | 目安 |
|------|------|
| 最近点対 | O(n log n) |
| 全対比較 | O(n²)（n 小さいとき） |

### つまずき

- sqrt 比較で **誤差 WA**  
- strip 内の **8 点チェック** を省略

### 最近点対（分割統治法）

→ [solutions/python/07/scc/](../solutions/python/07/scc/) / [solutions/go/07/scc/](../solutions/go/07/scc/)

```python
def scc(g, n):
    order = []
    seen = [False] * n

    def dfs(v):
        seen[v] = True
        for to in g[v]:
            if not seen[to]:
                dfs(to)
        order.append(v)

    for i in range(n):
        if not seen[i]:
            dfs(i)

    rg = [[] for _ in range(n)]
    for v in range(n):
        for to in g[v]:
            rg[to].append(v)

    comp = [-1] * n
    cid = 0
    seen = [False] * n

    def rdfs(v):
        seen[v] = True
        comp[v] = cid
        for to in rg[v]:
            if not seen[to]:
                rdfs(to)

    for v in reversed(order):
        if not seen[v]:
            rdfs(v)
            cid += 1
    return comp, cid
```

```go
func scc(g [][]int, n int) ([]int, int) {
	order := []int{}
	seen := make([]bool, n)
	var dfs func(v int)
	dfs = func(v int) {
		seen[v] = true
		for _, to := range g[v] {
			if !seen[to] {
				dfs(to)
			}
		}
		order = append(order, v)
	}
	for i := 0; i < n; i++ {
		if !seen[i] {
			dfs(i)
		}
	}
	rg := make([][]int, n)
	for v := 0; v < n; v++ {
		for _, to := range g[v] {
			rg[to] = append(rg[to], v)
		}
	}
	comp := make([]int, n)
	for i := range comp {
		comp[i] = -1
	}
	cid := 0
	seen = make([]bool, n)
	var rdfs func(v int)
	rdfs = func(v int) {
		seen[v] = true
		comp[v] = cid
		for _, to := range rg[v] {
			if !seen[to] {
				rdfs(to)
			}
		}
	}
	for i := n - 1; i >= 0; i-- {
		v := order[i]
		if !seen[v] {
			rdfs(v)
			cid++
		}
	}
	return comp, cid
}
```

```python
def sat2_solvable(implications, n_vars):

    for a, b in implications:
        g[a].append(b)
```

### 離散対数（BSGS 入門）

→ [solutions/python/07/discrete_log/](../solutions/python/07/discrete_log/) / [solutions/go/07/discrete_log/](../solutions/go/07/discrete_log/)

```python
def bsgs(a, b, p, m):
    """a^x = b (mod p), 0 <= x < m。存在しなければ -1"""
    a %= p
    b %= p
    step = int(m**0.5) + 1
    baby = {1: 0}
    cur = 1
    for j in range(1, step + 1):
        cur = cur * a % p
        if cur not in baby:
            baby[cur] = j
    factor = pow(a, step * (p - 2), p)
    gamma = b
    for i in range(step + 1):
        if gamma in baby:
            return i * step + baby[gamma]
        gamma = gamma * factor % p
    return -1
```

```go
	res := 1
	a %= p
	for e > 0 {
		if e&1 == 1 {
			res = res * a % p
		}
		a = a * a % p
		e >>= 1
	}
	return res
}

func bsgs(a, b, p, m int) int {
	a %= p
	b %= p
	step := int(math.Sqrt(float64(m))) + 1
	baby := map[int]int{1: 0}
	cur := 1
	for j := 1; j <= step; j++ {
		cur = cur * a % p
		if _, ok := baby[cur]; !ok {
			baby[cur] = j
		}
	}
	factor := powMod(a, step*(p-2), p)
	gamma := b
	for i := 0; i <= step; i++ {
		if j, ok := baby[gamma]; ok {
			return i*step + j
		}
		gamma = gamma * factor % p
	}
	return -1
}
```

### 中国剰余定理（CRT）

**霊夢**: 「3 で割ると 2 余り、5 で割ると 3 余り、7 で割ると 2 余る数」みたいなやつ？

**魔理沙**: そうだ。**中国剰余定理（CRT）** は、`x ≡ r_i (mod m_i)` という条件を何本か与えられたとき、それをまとめて **`x ≡ r (mod lcm(m_i))`** の 1 本にする。上の例なら x ≡ 23 (mod 105) だ。

**霊夢**: 競プロだとどこで使うの？

**魔理沙**: 主に 3 つだ。

| 場面 | 使い方 |
|------|--------|
| 周期の違う複数の条件 | 「信号 A は 3 秒周期、B は 5 秒周期で同時に青になるのはいつか」 |
| mod が NTT 非対応（例: 10^9+7） | NTT 向きの素数 3 つで畳み込み、CRT で元の値に戻す |
| mod が合成数 | 素数べきごとに計算して CRT で合成する |

### CRT の手順（2 本ずつまとめる）

1. 今までの条件を `x ≡ r0 (mod m0)` とする（最初は r0=0, m0=1）  
2. 次の条件 `x ≡ r1 (mod m1)` を加える。`x = r0 + m0 t` とおくと `m0 t ≡ r1 − r0 (mod m1)`  
3. g = gcd(m0, m1) が `r1 − r0` を割り切らなければ **解なし**  
4. **拡張ユークリッドの互除法** で m0 の逆元（mod m1/g）を求めて t を出し、`r0 += m0 t`、`m0 = lcm(m0, m1)` に更新  

**霊夢**: 拡張ユークリッドって？

**魔理沙**: [01.md](01.md) の GCD を拡張して、`a x + b y = gcd(a, b)` を満たす x, y も一緒に求める方法だ。mod が素数でなくても逆元が求まる（gcd が 1 のとき）。

→ [solutions/python/07/crt/](../solutions/python/07/crt/) / [solutions/go/07/crt/](../solutions/go/07/crt/)

```python
def ext_gcd(a: int, b: int) -> tuple:
    """a*x + b*y = g = gcd(a, b) となる (g, x, y) を返す"""
    if b == 0:
        return a, 1, 0
    g, x, y = ext_gcd(b, a % b)
    return g, y, x - (a // b) * y

def crt(rs: list, ms: list) -> tuple:
    """x ≡ rs[i] (mod ms[i]) をすべて満たす x を (x, lcm) で返す。解なしなら (0, -1)。
    法どうしが互いに素でなくてもよい"""
    r0, m0 = 0, 1
    for r1, m1 in zip(rs, ms):
        r1 %= m1
        # x = r0 + m0 * t として、m0 * t ≡ r1 - r0 (mod m1) を解く
        g, p, _ = ext_gcd(m0, m1)
        if (r1 - r0) % g != 0:
            return 0, -1  # 矛盾（解なし）
        t = (r1 - r0) // g * p % (m1 // g)
        r0 += m0 * t
        m0 = m0 // g * m1
        r0 %= m0
    return r0, m0
```

```go
// extGcd は a*x + b*y = g = gcd(a, b) となる (g, x, y) を返す。
func extGcd(a, b int) (int, int, int) {
	if b == 0 {
		return a, 1, 0
	}
	g, x, y := extGcd(b, a%b)
	return g, y, x - (a/b)*y
}

func floorMod(a, m int) int {
	a %= m
	if a < 0 {
		a += m
	}
	return a
}

// crt は x ≡ rs[i] (mod ms[i]) をすべて満たす x と lcm を返す。解なしなら lcm = -1。
// 法どうしが互いに素でなくてもよい。lcm が int64 を超える入力は想定しない。
func crt(rs, ms []int) (int, int) {
	r0, m0 := 0, 1
	for i := range rs {
		r1, m1 := floorMod(rs[i], ms[i]), ms[i]
		// x = r0 + m0 * t として、m0 * t ≡ r1 - r0 (mod m1) を解く
		g, p, _ := extGcd(m0, m1)
		if (r1-r0)%g != 0 {
			return 0, -1 // 矛盾（解なし）
		}
		t := floorMod((r1-r0)/g*p, m1/g)
		r0 += m0 * t
		m0 = m0 / g * m1
		r0 = floorMod(r0, m0)
	}
	return r0, m0
}
```

### 原根を求める

**霊夢**: さっきの「NTT の G=3 は原根」って、どうやって見つけるの？

**魔理沙**: 素数 p の **原根** g は、g^1, g^2, …, g^(p−1) が mod p で 1〜p−1 をすべて 1 回ずつ取る数だ。判定は「p−1 の **すべての素因数 q** について g^((p−1)/q) ≠ 1」を確かめるだけでいい。小さい g から順に試すと、すぐ見つかる。

→ [solutions/python/07/primitive_root/](../solutions/python/07/primitive_root/) / [solutions/go/07/primitive_root/](../solutions/go/07/primitive_root/)

```python
def primitive_root(p: int) -> int:
    """素数 p の最小の原根 g を返す。
    g が原根 ⇔ p-1 のすべての素因数 q について g^((p-1)/q) ≠ 1 (mod p)"""
    if p == 2:
        return 1
    qs = prime_factors(p - 1)  # p-1 の素因数（重複なし）。03.md の factorize と同じ要領
    g = 2
    while True:
        if all(pow(g, (p - 1) // q, p) != 1 for q in qs):
            return g
        g += 1
```

```go
// primitiveRoot は素数 p の最小の原根を返す。

func primitiveRoot(p int) int {

		return 1
	}

			if powMod(g, (p-1)/q, p) == 1 {
				ok = false
				break
			}
		}
		if ok {
			return g
		}
	}
}
```

#### agc020_c（部分和 DP（bitset）・対称性）

→ [solutions/python/07/agc020_c/](../solutions/python/07/agc020_c/) / [solutions/go/07/agc020_c/](../solutions/go/07/agc020_c/)

**問題（要約）**: N 個の正の整数の、空でない部分集合の和を全部並べたときの中央値を求める（N, A_i ≤ 2000）。 問題文は [AtCoder](https://atcoder.jp/contests/agc020/tasks/agc020_c) で読むこと。

**霊夢**: 部分集合は 2^N 個もあるよ。

**魔理沙**: **対称性** を使う。部分集合の和 s と、その補集合の和 total − s は 1 対 1 に対応する。空集合も入れた 2^N 個の和を並べると、ちょうど真ん中で s と total − s が入れ替わる。だから答えは **total / 2 以上で作れる最小の部分和** だ。

**霊夢**: 「作れる部分和」を全部知るには？

**魔理沙**: 部分和 DP を **bitset** でやる。「i ビット目が 1 ⇔ 和 i が作れる」とすれば、要素 x を足す遷移は `bits |= bits << x` の 1 行だ。Python は int がそのまま巨大な bitset になる。Go は `uint64` の配列でシフトと OR を書く。

```python
import sys

def main() -> None:
    input = sys.stdin.readline
    n = int(input())
    a = list(map(int, input().split()))
    total = sum(a)
    # 部分和 s と「残り」total - s は 1 対 1 に対応する（対称性）。
    # 空集合を含めた 2^N 個の部分和の中央で、total / 2 以上の最小の部分和が答え。
    bits = 1  # i ビット目が 1 ⇔ 部分和 i が作れる（Python の int を bitset として使う）
    for x in a:
        bits |= bits << x
    bits >>= (total + 1) // 2  # total / 2 以上の部分だけ残す
    low = bits & -bits  # 一番下の 1 のビット
    print((total + 1) // 2 + low.bit_length() - 1)

if __name__ == "__main__":
    main()
```

```go
package main

import (
	"bufio"
	"fmt"
	"math/bits"
	"os"
)

// orShift は b |= b << s（b は uint64 を並べた bitset）
func orShift(b []uint64, s int) {
	ws, bs := s/64, uint(s%64)
	for i := len(b) - 1; i >= ws; i-- {
		v := b[i-ws] << bs
		if bs > 0 && i-ws-1 >= 0 {
			v |= b[i-ws-1] >> (64 - bs)
		}
		b[i] |= v
	}
}

func main() {
	in := bufio.NewReader(os.Stdin)
	out := bufio.NewWriter(os.Stdout)
	defer out.Flush()

	var n int
	fmt.Fscan(in, &n)
	a := make([]int, n)
	total := 0
	for i := range a {
		fmt.Fscan(in, &a[i])
		total += a[i]
	}
	// i ビット目が 1 ⇔ 部分和 i が作れる
	b := make([]uint64, total/64+1)
	b[0] = 1
	for _, x := range a {
		orShift(b, x)
	}
	// 部分和 s と total - s は 1 対 1 に対応するので、total / 2 以上の最小の部分和が答え
	for v := (total + 1) / 2; v <= total; v++ {
		w := b[v/64] >> uint(v%64)
		if w != 0 {
			fmt.Fprintln(out, v+bits.TrailingZeros64(w))
			return
		}
		v += 63 - v%64 // この 64 ビットの塊には 1 がない → 次の塊へ
	}
}
```

#### agc022_c（コストの大小で貪欲）

→ [solutions/python/07/agc022_c/](../solutions/python/07/agc022_c/) / [solutions/go/07/agc022_c/](../solutions/go/07/agc022_c/)

**問題（要約）**: 各要素を「k で割った余りに置き換える（置き換えないことも選べる）」操作（コスト 2^k）を繰り返し、数列 a を b に変える最小コストを求める（値は 50 以下）。 問題文は [AtCoder](https://atcoder.jp/contests/agc022/tasks/agc022_c) で読むこと。

**霊夢**: どの k をどの順で使うか、組み合わせが多すぎる……

**魔理沙**: コストに注目しろ。**2^k は 2^1 + 2^2 + … + 2^(k−1) より大きい**。だから「大きい k を使わずに済むなら、小さい k を全部使ってでも避けた方が得」だ。k = 50 から順に、使う集合から外してみて、まだ全部の a_i を b_i にできるなら外したままにする。

**霊夢**: 「できるか」の判定は？

**魔理沙**: 値は 0〜50 だけなので、「v から v % k へ行ける」辺を張った 51 頂点のグラフで **到達可能性**（ワーシャルフロイド）を調べればいい。小さい k ほど余りが小さいので、大きい k から順に使えば同じ k を 2 回使う意味はない。

```python
import sys

MAXV = 50

def reachable(allowed: set) -> list:
    """reach[v][w]: v から、allowed の k で余りを取る操作を繰り返して w にできるか"""
    reach = [[v == w for w in range(MAXV + 1)] for v in range(MAXV + 1)]
    for v in range(MAXV + 1):
        for k in allowed:
            reach[v][v % k] = True
    for mid in range(MAXV + 1):  # ワーシャルフロイドで推移閉包
        for v in range(MAXV + 1):
            if reach[v][mid]:
                rv, rm = reach[v], reach[mid]
                for w in range(MAXV + 1):
                    if rm[w]:
                        rv[w] = True
    return reach

def main() -> None:
    input = sys.stdin.readline
    n = int(input())
    a = list(map(int, input().split()))
    b = list(map(int, input().split()))

    def ok(allowed):
        r = reachable(allowed)
        return all(r[x][y] for x, y in zip(a, b))

    allowed = set(range(1, MAXV + 1))
    if not ok(allowed):
        print(-1)
        return
    # 2^k は 2^1 + ... + 2^(k-1) より大きいので、大きい k から「使わずに済むか」を決める
    for k in range(MAXV, 0, -1):
        allowed.discard(k)
        if not ok(allowed):
            allowed.add(k)
    print(sum(1 << k for k in allowed))

if __name__ == "__main__":
    main()
```

```go
package main

import (
	"bufio"
	"fmt"
	"os"
)

const maxV = 50

// reachable[v][w]: v から、allowed の k で余りを取る操作を繰り返して w にできるか
func reachable(allowed []bool) [maxV + 1][maxV + 1]bool {
	var r [maxV + 1][maxV + 1]bool
	for v := 0; v <= maxV; v++ {
		r[v][v] = true
		for k := 1; k <= maxV; k++ {
			if allowed[k] {
				r[v][v%k] = true
			}
		}
	}
	for mid := 0; mid <= maxV; mid++ { // ワーシャルフロイドで推移閉包
		for v := 0; v <= maxV; v++ {
			if r[v][mid] {
				for w := 0; w <= maxV; w++ {
					if r[mid][w] {
						r[v][w] = true
					}
				}
			}
		}
	}
	return r
}

func main() {
	in := bufio.NewReader(os.Stdin)
	out := bufio.NewWriter(os.Stdout)
	defer out.Flush()

	var n int
	fmt.Fscan(in, &n)
	a, b := make([]int, n), make([]int, n)
	for i := range a {
		fmt.Fscan(in, &a[i])
	}
	for i := range b {
		fmt.Fscan(in, &b[i])
	}
	ok := func(allowed []bool) bool {
		r := reachable(allowed)
		for i := range a {
			if !r[a[i]][b[i]] {
				return false
			}
		}
		return true
	}
	allowed := make([]bool, maxV+1)
	for k := 1; k <= maxV; k++ {
		allowed[k] = true
	}
	if !ok(allowed) {
		fmt.Fprintln(out, -1)
		return
	}
	// 2^k は 2^1 + ... + 2^(k-1) より大きいので、大きい k から「使わずに済むか」を決める
	for k := maxV; k >= 1; k-- {
		allowed[k] = false
		if !ok(allowed) {
			allowed[k] = true
		}
	}
	var ans int64
	for k := 1; k <= maxV; k++ {
		if allowed[k] {
			ans += 1 << k
		}
	}
	fmt.Fprintln(out, ans)
}
```
