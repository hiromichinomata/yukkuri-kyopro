# 執筆例（依頼の出し方）

## 新規執筆

```
@yukkuri-kyopro-chapter docs/01.md を目次に沿って執筆してください。
コードブロックは多め、solutions も同期してください。
```

## 既存章の追記

```
@yukkuri-kyopro-chapter docs/03.md の「3.2 二分探索」だけ書いてください。
abcxxx_d を 🎯 に 1 問入れ、12.md も更新してください。
```

## 解説を厚くする（実装は維持）

```
@yukkuri-kyopro-chapter docs/03.md の各テクニックに解説を厚くしてください。
イメージ・いつ使う・計算量・つまずきを足す。Python/Go の実装ブロックは削らず全文維持。
```

完了時に「追加した解説」と「維持したコードブロック（Python/Go 各○個）」を報告する。

## solutions のみ同期

```
@yukkuri-kyopro-chapter docs/00.md に載っているコードを solutions/python/00 と go/00 に同期し、リンクを足してください。
```

## 付録

```
@yukkuri-kyopro-chapter docs/11.md スニペット集を執筆。01 の template をベースに表形式で整理してください。
```

## 完了報告に含めるもの

- 更新したファイル一覧
- 追加した AtCoder 問題 ID（あれば）
- 実行したテストコマンドと結果
- 解説リライト時: **Python/Go コードブロックを削っていないこと**（減った場合は理由を明記）
